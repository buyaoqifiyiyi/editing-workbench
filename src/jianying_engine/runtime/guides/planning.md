# 剪辑创作决策层

本层负责把实际素材变成有依据的创作决定，制作与修订中持续使用。执行层把决定映射到当前软件的可编辑操作。对用户保持简短方向和关键取舍；详细源时码、连接依据和修订留在项目分析、脚本或交付说明中，不要求用户审核逐镜头表。

先按工作台本轮软件配置识别组合或单独调用及所选职责。单独特效、调色或音频任务只使用相关创作判断，不强制建立主剪辑时间轴。剪映使用[剪映执行指南](editing.md)，达芬奇使用[达芬奇接口](../references/resolve-workflow.md)，AE使用[独立AE调用](../references/adobe-workflow.md#独立ae调用)。旧会话未绑定软件选择时沿用实际工程，不套新会话默认。各软件都是工作台内持续适配的后端，原生数据不互通不影响分别使用；原生能力按当前后端指南验证。

Agent统一Skill为`editing-workbench`。软件后端选择器支持按职责组合和单独调用，选择随会话保存；新会话初值来自保存的默认配置。每轮以后端配置块为准，避免历史回合残留旧选择。用户明确要求与配置冲突时说明具体差异，不静默切换宿主或改写已有工程。

## 分流（唯一维护位置）

按创作要求是否明确分流，与是否新项目无关：

| 情况 | 做法 |
|---|---|
| 只有素材或笼统的“帮我剪一下”，且未授权自主决定 | 轻量查看实际素材，提供简短方向，等待用户选择 |
| 已给脚本、指定模仿视频，或明确了主题、表达、风格、结构等方向 | 保留已有要求，直接进入相关创作判断；细节自行决定，不追加方向选择 |
| 已选定方向或明确让Agent自主决定并直接剪 | 按下述流程自行取舍并执行，不增加确认 |
| 明确的局部修改 | 保留认可内容，只检查受影响的镜头、阅读、声音和相邻连接；不重剪全片 |
| 用户主动要求比较或重新考虑方向 | 按请求给选项，即使已有脚本或参考 |

用户只要建议或拆解时，以相应文本为终点，不创建工程、build/publish或操作宿主。原请求包含制作时，方向确定或要求拆解后直接执行。核心目标冲突、不可替代素材缺失或新增付费才需要用户决定；工作台已授权自主剪辑时遵循其交互约定。

## 创作判断流程

动漫、游戏情绪混剪和MV先读[漫剪与节奏混剪](../references/styles/anime-mix.md#镜头与音乐如何共同推进)，其他片型按[通用方法](../references/general-editing.md)与对应类型展开。每步只留下影响后续操作的判断，已有有效分析可复用。

### 1. 从连续素材确认事件

先筛选，再对选中范围及切点前后精看。找人物在做什么、注意力在哪里、动作怎样开始和结束、反应由什么触发，以及原片内部切点。景别、视线、运动方向、主体位置、光色和物件是连接线索；文件名、单张好看的截图或剧情常识不能代替镜头证据。

在项目分析里保留选中源范围与观察依据，区分画面事实、剧情推断和待核实项。抽帧只支持可见构图；运动相位和连续性要用足够密集的时序画面或可用的正常速度播放核实，声音另行试听。工具不能播放、监听或读取参考时，标出具体未核实项，采用有依据的选段和条件性方案，不宣称已经看懂连续运动或精准卡点。

完成条件：主线使用的画面能对应到实际源段，关键动作、关系和声音的证据状态清楚。没有原素材时仅给设计建议，不编镜头、台词或精确时码。

### 2. 建立有镜头依据的表达

用一句可执行主张说明观众将看到什么变化，例如“由两人的相互回应走向单人空镜”，再找支撑关系、变化和结尾的不同镜头。区分动作展示、关系推进、意象联想和纯视觉节奏，决定本片及各段由谁主导。已有脚本或参考时先落实其意图，不重新编写用户明确的内容。

从素材决定进入点、信息出现顺序、情绪转折与结束位置；段数、高潮、快慢和长度随内容产生。为主视觉选择有素材依据的色彩、形状、空间或文字语言，在需要呼应处发展，重要转折允许改变。素材缺少关系或结果时调整结构、说明缺口，不用泛化文案补造剧情。

完成条件：关键段落各自改变了信息、关系或感受，能指出实际画面依据；相同作用的冗余镜头已有取舍。

### 3. 让声音与画面共同组织时间

用户已指定BGM并要求自动匹配镜头/意境或卡点时，先按[原生视听与音乐编排](../references/music-edit.md)检查当前配置的协议、模型与凭据；就绪后将明确源选区的实际BGM与连续视频送入该模型，再用节拍候选及动作锚点编译当前后端计划。配置缺失应说明视听分析尚未就绪，不自行假设供应商或模型。不得把均匀每N拍切镜、文字推测或指南本身当作完成声画匹配；模型返回的时间仍需量化与关键短段核实。

音乐主导时先确定实际BGM版本及源段，听乐句、音色/配器变化、停顿、重音和人声语义，再安排画面发展；原声主导时先保留动作因果、完整对白和反应。对重要声音事件判断由切镜、动作完成、构图到位、停留或反差响应。连续音乐可以承载变化的镜头密度，声音停顿也可以保留运动；拍点不是逐拍换镜的命令。

为关键转折选前后反差与辨认时间：哪里期待被建立，哪里得到释放，哪里应留住结果或余韵。核对歌词、对白、音效和BGM的主次及声画同步；波形、自动拍点和峰值只提供候选。具体声音组织见[混剪声音策略](../references/styles/anime-mix.md#bgm-与原声并置)。

完成条件：主要段落与声音变化有可解释的关系，镜头长度包含必要动作/阅读/反应，未试听部分没有被写成听感结论。

### 4. 在关键连接处作选择

先说清“前镜让人看哪里，后镜接住什么，连接后含义或感受怎样变化”。按[画面连接](../references/general-editing.md#从表达目标到画面连接)判断动作、视线、空间、信息、意象和声音的关系；延续、对照、跳跃或停顿都可以成立。

在决定风格、关系或节奏的关键接点，比较少量实质不同的剪法，例如继续动作与切反应、图形匹配与声音桥接、保持镜头与切近景。根据当前素材和目标选一个，简记取舍；普通明确接点直接决定，不为每一刀写评审表或多套完整时间轴。镜头关系不成立时重选或重排；缺少视觉锚点时可用有目的的裁切、构图或运动建立连接。

完成条件：关键接点有观看重心和关系依据，选择落到了源入出点、顺序、停留或声音边界，而非只有技巧名称。

### 5. 把技巧变成适量且可执行的表现

从连接要解决的问题选择技巧，核对素材前提、预期可见变化和退出后的主体状态，再查当前宿主支持。可在同一作品中发展景别、运动、层次、色彩、文字与声音的共同语言；表现丰富程度服从表达和用户要求，不由效果数量衡量。

同一种情绪可有不同做法，同一种技巧也可表达不同含义。悲伤不自动叠化，高潮不自动快切，重音不自动震动；依据实际前后文选择。以无该效果的剪法作必要对照，判断它是否增加关系、空间、触感或风格。明确需要技术展示时，设计可感知的开始、发展、停稳和交接，不能只交付基础拼接。

实现前区分：已有操作可直接完成、满足前提才可用、当前未接入。严格后端计划只写允许字段；创作说明保存在计划外，或该后端已支持的notes中。核心技法不可等价实现时说明具体缺口和取舍；常规细节可选有证据的替代，不静默删掉核心要求，不借研究资源绕过准入。

完成条件：选中技巧有表达作用、素材前提和真实执行路径，实际操作与未实现意图能够分开核对。

### 6. 用短段结果回看决定

初版优先检查能代表主要风格或风险的段落及前后衔接。用当前工具和后端允许的预览、时序画面或音频输出，复核注意力是否接住、动作/反应是否看清、音乐推进是否匹配、效果是否遮盖内容。静帧、时序采样、试听、连续播放、保存重开和导出分别记录；证据不足时保持未核实状态。

存在关键不确定性时，只在同一源素材、BGM与目标下比较受影响短段的不同剪法，改变明确变量，选定后再展开；无需默认生成多部成片。已有证据足够就继续交付，不反复验证无变化部分。具体比较与用户偏好积累见[短段比较与反馈积累](../references/creative-review.md#短段比较与反馈积累)。

完成条件：发现的问题已回到选段、顺序、声音、切点或表现修正，交付说明准确区分完成与未验；主观质量最终以实际片段和用户观看反馈为准。

## 给用户的方向与交接

方向未定时，默认提供三个有实质差异的简短方向；素材只支撑两个时说明理由，用户指定数量时照办。差异来自表达、组织顺序、节奏或声画主次，每项说明观众感受、大致做法与影响选择的限制，并推荐一个。没看过素材时给条件性建议，不编成本、热度或效果保证。

参考视频先确认能读取视频本身，区分“按此模仿”与“仅供了解素材”；实际拆解结构、镜头关系、构图、文字与声音，再映射到自有素材。参考取不到时说明缺口，封面、标题和评论不能当作观片结果。只有成片时，作者具体轨道、效果名称与参数属于待验证实现候选。

交接使用项目已有分析、脚本或说明，保留中心主张、选中源段、声画转折、关键连接、技法取舍及未核实项，按实际需要记录，不另建强制表单。执行层继续此判断流程，局部修订只复查受影响部分；建议不等于用户已选，后台任务成功也不等于审美或完整视听通过。
