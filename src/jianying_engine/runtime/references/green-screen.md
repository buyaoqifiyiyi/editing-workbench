# 绿幕与色度抠除：跨类型的合成方法

## 选型依据

绿幕是准备可分离前景的一种方法，色度抠除是按颜色去除背景的操作。它们属于跨影片类型的共同技法，按素材条件和合成目的选用，不归漫剪专属，也不要求每种影片都用。绿色、蓝色及其他合适的单色背景都可作为取色对象；背景色不能与要保留的主体颜色混淆。

先区分三种素材：

| 素材条件 | 处理选择 | 关键判断 |
|---|---|---|
| 已有相对均匀的单色背景 | 原生色度抠除；必要时结合静态蒙版排除无关区域 | 主体有同色衣物、道具、反光时会误抠除；背景阴影、色差、压缩及运动模糊会影响边缘 |
| 已有透明通道的原素材 | 直接作为透明前景叠加 | 实际检查透明区域；不能从 `.mov` 等扩展名推断必有透明通道 |
| 普通复杂背景影片 | 判断原生智能抠像、自定义抠像或蒙版是否适用 | 给整幅影片铺绿色底不等于分离人物；单色键不能识别复杂背景中的人物轮廓 |

如果参与拍摄，先按主体衣物、产品、道具选幕色，尽量保持幕面照明均匀、主体与幕分开，减少投影和反射染色。后期提高强度不能自动补救差的原素材。已有片源则按实际条件挑选镜头或分段处理，不假定它可重新拍摄。要让物体从屏幕或道具里出现、或被替换时，优先用同机位、同光线的两次实拍提供真实运动：在手势接触或停顿的瞬间切换，对齐物体的大小、位置和角度，保留真实投影；只能用缩放动画替代时说明差异。

## 跨类型应用

| 成片类型 | 适用目的 | 保留的表达重点 |
|---|---|---|
| 漫剪／节奏混剪 | 主体与字、动态图形前后穿插；主体组入场；背景独立运动 | 动作、眼神和关键姿态清楚；不能用持续抖动掩盖层次缺失 |
| Vlog／旅行／生活记录 | 人物与地图、地点标题、示意画面组合；局部屏幕内容替换 | 合成服务经历与地点表达，保留人物体验和自然声音；复杂现场素材先判断是否可分离 |
| 讲解／教程 | 主讲人与演示画面、图表、步骤同屏 | 信息可读、指示位置准确，给讲解与演示足够时间 |
| 纪录片／纪实 | 棚拍讲解与资料图、说明性示意组合 | 保留来源和事实语境；重建或示意需清楚标识，不能让合成暗示人物当时身处另一现场 |
| 商业／产品展示 | 产品换背景、屏幕替换、品牌图形与产品穿插 | 产品颜色、轮廓、标识、反光和功能展示准确；主体含幕色时先换策略 |

## 原生执行顺序

1. 写清背景、完整前景、图形、局部前景的层序，以及各层是否已有透明区域。确定合成是换背景、同屏展示还是穿插，不先堆效果。
2. 查看拟用范围的起点、终点及代表性运动画面，检查幕色变化、发丝、半透明物、主体同色区域与反光。必要时分片设置不同色键；不能以一帧干净推定全段干净。
3. 从实际背景取代表色。先用足够去除背景的较低强度，再检查主体是否出现洞、边缘收缩、残底或闪烁；逐项调整，不照搬教程 63、23 或接口默认 20。静态蒙版只用于适合的固定区域，不能冒充动态轮廓抠像。
4. 前景分离后再匹配背景的比例、位置、透视线索、亮度与必要的原生阴影。色键只提供透明区域，不自动完成透视、跟踪、立体感或运动。
5. 做前后穿插时复制同源前景，保持源范围、时间、速度、位置和缩放一致，再决定上层保留的局部。局部前景随动作不再适合固定蒙版时，重新选镜头或使用可执行的原生抠像方式。
6. 设计明确的运动状态：画外入场、到位、留出观看时间、背景变化、退出。组内保持关系，背景可以独立运动；抠干净的人物加静态大字仍不等于空间动效完成。使用已有人物遮罩时，保持人物前景独立，把后方底板图片与静态单行字组成两轨组；人物与组各自可用的运动和组合只按 [人物遮罩绑定](capabilities.md#matting) 的子集。源裁边看实际帧，并设静态前景信息底等明确观看边界。后方大字被遮挡时只承担层次，另设前方清楚小字负责信息；用前后层序对照检查脸部与重要动作，再核背景组中间状态。

复杂背景人物先检查完整选区，再处理边缘，最后检查运动中的稳定性。脸、头发、手臂或道具存在大块漏选时先补选区或换镜头；羽化只改边缘过渡，不能恢复被挖掉的主体。黑、灰、白底分别暴露亮边/残片、轮廓和漏选，随后换目标背景复核；不能用近似底色掩盖缺陷。游戏与真人按实际样本分别评估，起中尾静帧不能证明全段无闪烁、运动模糊或遮挡恢复合格；计算/绑定边界见[抠像研究](progressive-integration.md#02-智能手工抠像已有产物绑定已验证新计算仍暂存)。

复杂背景补选前对照原画面：花枝、道具等前景遮住人物时，遮挡区域没有可见人物像素；擦掉遮挡物会留下透明缺口，笔刷只能选择现有像素，不能恢复隐蔽的头发或身体。需要完整轮廓时优先改选无遮挡范围；需要保留遮挡关系时把遮挡物纳入创作判断并另验，不能把其残留称作干净人物抠像。连续补选不改善这一输入条件时停止细修，保留失败证据。

有实际alpha序列时，用相邻差异定位需要加看的时刻；先核源时间、切镜、主体运动与遮罩尺寸变化，再对照原画面和合成检查。无运动补偿或真实标注时，MAE/IoU只作候选指标，不当闪烁程度、准确率或质量评分；变化小仍须拒绝固定孔洞、漏选和背景残片。主体完整、边缘、时间稳定性依次过关后才设计人物穿插，不外部平滑alpha冒充原生补边。

2026-10-06 按 `scripts/editor.py` 及固定后端 `pyJianYingDraft==0.3.0` 的 `VideoSegment.add_chroma` 核对：视频片段可写 `chroma`，每片段一个色键。`color` 使用实际取色的 `#RRGGBBFF`；强度、阴影、边缘羽化和边缘清晰均为 0–100，回读保存值为输入值除以 100。

| 计划字段 | 本地接口对应含义 |
|---|---|
| `intensity` | 强度，省略时为 20 |
| `shadow` | 阴影，省略时为 0 |
| `edge_smooth` | 边缘羽化，省略时为 0，非零需会员策略开启 |
| `spill` | 边缘清晰，省略时为 0，非零需会员策略开启；不能只凭英文名就当作通用去绿边功能 |

用户会员授权已生效，按需要采用 `allow_vip_effects=true`，不重复确认。上述字段名称不证明具体片源的边缘已经处理好；边缘清晰与反射染色如何呈现仍以剪映实际画面为准。

当前可记录色键与视频层序/变换/蒙版参数，但组合呈现未准入。动态矩形、无羽化圆形/椭圆、单层局部复合、up_left透视及图片/速度1视频水平smoothstep分别按现行契约判断；曲线视频动态零羽化矩形仅沿 [曲线变速](capabilities.md#speed-curve-window) 的有限center_x/width子集，键time按真实曲线源映射，实际窗口中间状态另核（视频缓动不与色键/几何蒙版组合，已审阅人物缓存仅按下述绑定子集），不据此开放多色键/字幕直接色键/任意四角。用户明确授权界面参与时，可按[界面计算与后台复用流程](native-ui-advanced.md#人物抠像界面计算与后台复用)取得新原生遮罩并审阅，普通后台任务不自动转UI。已有自定义人物遮罩可按 [正式绑定子集](capabilities.md#matting) 复用；智能抠像新计算和跟踪仍暂存，普通生产不写入计划或`jianying_tasks`。必要功能缺失时说明真实缺口，不虚构字段。现成图形素材内部已有动画不等于其形状动画参数可原生修改。

所有新增抠像与效果保持剪映原生可调，不外部烘焙人物、文字或整组动画。采用额外素材仍按 [素材来源流程](stock-sources.md) 核对来源；公开教程不自动授权其人物、图形或示例成片用于交付。
