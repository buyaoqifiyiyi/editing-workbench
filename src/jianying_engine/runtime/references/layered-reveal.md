## 按画面目的选择方法

不是每次技术流剪辑都要使用本卡。先按成片类型、真实素材与声音确定表达目的；需要以下结构时再参考相应教程。层数、形状、入场方向和停留时间随内容设计，不套作者整条时间轴。

<a id="reveal"></a>
### 分层补齐新画面：ZZ-01 / ZZ-02

适合亮相、细节揭示或短暂重组。底层维持旧镜头，新镜头的副本在上层分别露出部分区域，按已核实的切点增加可见区域，最后恢复一层完整新镜头。不同区域应补充不同信息，而非重复同一动作的小缩图。明确开始、补齐、完整停留和交给下一镜头的状态；强变化后让主体或动作结果可读。

同源副本合拢时核对源时钟、fit、缩放、位置和旋转，依 [同源图层与共同中心](technique-combinations.md#同源图层与共同中心) 换算。错开轨道起点不等于延迟素材内容；若要保持同步，源入点随之调整。矩形窗口只保留原画面的一部分，不生成透明人物。

作者示例的 3/4 帧短间隔不作为固定配方。先从本片声音与动作决定事件时间，再按项目 fps 换算帧数；4 帧在 30fps 与 60fps 下持续时间不同。未试听时只记录暂定视觉节奏，不宣称精准卡点。闪白用于强调可辨认的变化边界，不掩盖未对齐的拼合。

<a id="split"></a>
### 渐进分屏：ZZ-03 / ZZ-07

分屏可以从一幅完整画面逐步形成，而不是一开始就铺满多个小窗。收窄已有窗口并调整素材位置，给新镜头腾出空间；按段落目的展示不同视角，最后由重点分区扩展或接回完整镜头。每条分区都有信息任务，重要脸部、动作落点与字幕不挤在边界。

分别设计窗口宽度与素材缩放：宽度改变可见范围，缩放改变对象大小，两者不能互相代替。尺寸取当前素材/画布基准，教程中的 3840、1920、960 属于其示例。

等分条带或互补窗口要能拼回完整画面：N 条等分时带宽为 W/N，第 i 条（从 0 计）中心 x = (i+0.5)·W/N − W/2，先按像素算，再换成蒙版单位；同源条带用同一个 source_in。拼合后截静帧检查接缝，可把一层临时换成纯色底看有无漏缝或重叠，确认后换回；黑条只在有意分隔时保留，对齐用的辅助线不留在成片里。屏风条带须同源同步、同步换素材；上下黑斜边建立的是二维空间暗示，不据标题推断三维面板旋转。

<a id="subject"></a>
### 主体连续、背景变化：ZZ-05 / ZZ-06 / ZZ-08 / ZZ-10

适合角色介绍、回忆或同类物体串联。先让人物、汽车等对象承担注意力锚点，再让背景窗口、照片或信息发生变化。换场前后核对主体位置、大小、姿态、朝向及光照；颜色与尺度反差建立选中状态，最后回完整动作。剪影底层与彩色前景应对齐，不能在强调结束时跳回另一姿态。

高速回忆放在背景，前景与关键文字保持可辨认；回忆镜头应有内容联系，不能为了快闪补入无关经历。角色姓名与身份核实，装饰雷达图不写成能力值结论。预制剪影、绿幕人物、相机框和轮廓素材是明确的输入条件；普通带复杂背景的片源不能默认等价替换。前景分离按 [绿幕与色度抠除](green-screen.md) 判断，不由几何窗口冒充。

<a id="occlusion"></a>
### 接触与遮挡建立动作因果：ZZ-04 / ZZ-09

人物推屏的典型底到顶关系是：背景人物、下层手部、面板、上层接触手指。面板运动与手指接触边缘协调，背景随动作露出，才有被推动的感觉。钥匙齿与楼房对齐后，接触处短暂位移并回收，形成图形之间的响应。看重点接触时刻和中间状态，而不只核对首尾位置。

原教程录屏内的编辑器轨道及已经制作好的后续转场视频，不是本次工程的可编辑内部结构。交付要求保留原生参数时，面板内容与后续视觉变化须用本次可支持的轨道重新设计；不可把教程视频或完整效果烘焙当作同款原生实现。手指轮廓、智能抠像等缺口仍依当前能力判断。

<a id="motif"></a>
### 具体物象承接内容：ZZ-06 / ZZ-08 / ZZ-09

从用户素材中找有依据的物件、动作或关系，再设计呼应：选择对应角色亮相，回忆对应已发生事件，道具形状对应场景轮廓。先说明它让观众看懂什么，再选择运动与图形。不要因教程用了婚书、能力图或钥匙，就给另一个人物编造经历或剧情；没有合适内容联系时改用接剪或其他设计。

## 执行条件与证据边界

本卡不维护另一份能力表。按 [能力状态](capabilities.md) 与 [计划格式](plan-format.md) 核对当前子集后写计划；位置/缩放/不透明度与动态矩形等已有操作可支持部分组织方法，不因此认定整条教程已接入。

- 镜面、线性、钢笔蒙版、轮廓抠像与描边、曲线变速、原生缓动、贴纸/模板等分别核对，不从教程画面或近似资源名推断可执行。图片及速度1视频两点水平 smoothstep 的已接入子集，也不等同作者的多属性三次方缓动或任意视频组合。
- 普通模糊不能冒充运动模糊，已有调色子集不能自动扩大为任意黑白或剪影处理，二维透视不能冒充三维摄像机。
- 暂存效果保留来源与作用，但普通生产不自动调用、不添加为待办或转入UI补做。用户另行要求研究/复现时再按现有流程核实；本次维护未新增执行字段或解除停用。
- 补帧、光流插帧、平滑慢放帧融合和超分等画质增强依用户分工排除，出现于教程不表示进入待研究接入清单。
- 素材准备、轮廓质量、源时间对齐与多层预览是成本。先满足主体/文字阅读和有效事件，不按教程数量延长影片。音效列表、波形或字幕中的拍点只证明操作记录，不能代替试听与混音判断。

实际任务在现有 notes 中简记采用的方法、源范围、底到顶层序、声音依据、恢复完整画面的时刻和具体缺口，无需增加专用schema或逐层确认。
