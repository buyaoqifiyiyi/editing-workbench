# 模板分析得到的图层与信息组织方法

已形成设计但需要多图、滚动、文字或信息运动依据时使用。这里只保留可迁移判断；原工程、逐模板数值、封面和检验记录在外部数据/项目目录。实际局部重建准入查 [模板工具](template-library.md)，本页不宣称整套模板可用。

| 目的 | 可复用判断 |
|---|---|
| 照片墙收束 | 先定共同中心和各图初始尺寸，位置与尺度共同变化；聚拢后的小图不承担阅读，重要内容在之前或后续主画面落稳 |
| 轮播/错峰 | 按信息主次设计入场、到位、观看与退出，不只复制轨道起点；某层落稳时其他层可以补齐，避免同时变化丢失落点。重叠的层各占一条独立轨，底层保持明确背景；每层起点按素材完整入画位置与声音证据计算，教程示例间隔（如 d=0.3、m=0.15）不作默认 |
| 连续滚动 | 按图片实际尺寸统筹间距、中心通过时点和窗口；需要读图时加中心停顿或分组，不能照搬旧片间隔。所有复制层走同一条运动路径，复制后只换素材、不改关键帧：下一层起点放在上一层刚完整入画的时刻，相邻两张无缝衔接；放在上一层居中的时刻，同屏可见两张。在交接时刻截静帧，确认无空隙、无重叠 |
| 滚动名单 | 位移距离 = 名单总高 + 可视区高（从画外完全进入到完全离开），匀速；时长按行数和可读速度决定；并列画面缩成小窗给名单留区。检查每行可读时间够、首尾不出现空屏，姓名依用户资料核实 |
| 信息文字 | 先设计最终阅读构图，留足停留，再安排短时离场；密集运动点只证明参数，不能称为原生缓动 |
| 产品展示 | 先识别产品，再补细节/卖点，最后行动或身份；原模板文字、价格和宣传结论不作为新产品事实 |
| 二维空间 | 层间相对速度、大小和遮挡可建立空间层次；模板标题写3D不证明三维相机、景深或跟踪 |

旧 sticker 轨可能绑定文字材料，先读真实材料类型，不能仅看轨名判断；当前借鉴器没有相应准入时按 caption schema 重设计，不宣称整段字效迁移。

预合成背景和可编辑槽位分开：片内旗帜、云层、粒子或形状若只有一个源视频，就没有独立原生参数。学习背景铺垫/标题落位关系不等于能够重建其所有动画，也不自动取得素材或字体使用权。

同轨重叠、负时间或越界旧关键帧须明确格式与时间基准，不夹断坐标/时间获得通过。先保留最小失败证据，再专项核验；自主重设计是新表达，不能称为原运动等价迁移。

这些方法不改变原素材优先、原生可编辑、暂存能力及用户最终检查/导出的边界。
