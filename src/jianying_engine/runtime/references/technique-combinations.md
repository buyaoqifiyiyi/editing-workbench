# 跨教程组合方法

适用于需要构图、层次、运动或声音组织的段落。先按成片类型判断是否需要设计，再按本页选择方法；不把全部组合塞进同一作品。当前字段与能力统一查 [能力状态](capabilities.md) 和 [计划格式](plan-format.md)，本页不新增接口。方法出处的原始观片记录在 Skill 外，检索入口见 [教学索引](tutorial-library.md)。

## 技术流段落如何组织

照片墙收束、相册队列、错峰多图及文字信息段，可按需查 [模板图层编排与信息运动](template-layout-patterns.md) 的工程参数样本，先确定观看顺序和阅读时间，再设计共同运动与交接；原背景已合成的视频不计入新增原生技法。

先写清这段展示什么以及观众要看哪里。为所选素材设计开始、到位、停留和释放的构图；按需要让画中画、蒙版、文字、背景和原生效果分别承担不同职责。滤镜主要改变色彩，特效可以强化冲击，二者不能替代图层关系和运动设计。相邻镜头原有色彩关系连贯时保留原色对照，不为增加技法强行暖化/提亮；亮度或像素差统计只量化变化，不代表颜色匹配或观感评分。

技术密集段仍要有主视觉。分区应避开关键脸部、刀锋、落点和重要字幕；多个分区不必同时更新。用清楚全屏画面承接强变化，避免为了展示技法延长重复镜头。普通连续动作、纪实或信息密集段可以只做接剪。

需要加强技术展示时，让观众看见构图如何发展与交接。例如完整动作收为首窗，其他动作逐次填充，整组倾转后由下一动作的蒙版揭示接管；或同源条片错位进入、回正合拢，再交还完整动作。按动作方向、形状与观看重心选择其中合适的变化，不把这套顺序固定成模板。各窗要有辨认时间，到位后仍检查源动作是否推进；层在运动不能掩盖人物长期近静态。[修订与表达判断](creative-review.md) 提供核验要点；不以增加轨道、关键点或资源数量替代可见变化。

常见段落的执行要点：

- **交错快闪**：每张短片段打头、中、尾三个关键帧（透明度 0→1→0，同时缩小或横移），下一张从上一张的中点开始，至少两条轨交替，主轨保留连续底层。检查交接帧里没有全透明的空帧。
- **定格**：给定格一个能感知的起点（闪光、快门或打字音效、短震动、音乐进入），并和运动段拉开状态差（缩小倾斜成照片、降饱和、背景模糊），否则看起来像卡帧。检查定格首帧前后有声画触发，停留够读完配字。
- **调色诊断**：先看亮度波形分出暗、中、亮区，再看 RGB 分量或矢量判断偏色方向，只改出问题的分区。同一偏色既可降对立色，也可提另外两色，色相趋势相近但亮度变化相反，按画面明暗需要选。动漫或插画不按真人肤色线校准；示波器刻度不代表素材位深，升规格也不恢复源细节。

在任务分析或 notes 简记：源范围、声音依据、从底到顶的层序、各层职责、共同变化时点和必要缺口。不增加专用 schema 或每层确认步骤；用户通常需要的是完整结果。

## 同源图层与共同中心

重复同一镜头进行局部强调或拼合时，时间轴时刻 T 对应的源位置为 `source_in + (T - start) × speed`。各层起点错开但要保持同步时，相应调整 source_in；先将 start 量化到项目帧网格，再用实际起点差计算源入点和归位时间，不能沿用量化前的偏移。仅裁掉前段不代表每层都从同一 source_in 开始。核对同源层的 fit、缩放和坐标，避免人物在分区边界断裂。刻意时差另说明用途。同位置的同源副本只调透明度不会产生可见变化；局部提亮或闪亮要用亮度调节、滤镜或特效，不能拿 alpha 动画交付。

整组缩放或平面旋转围绕共同中心 c 计算各层中心：`p_new = c + s × R(theta) × (p_old - c)`。计算前统一像素或画布坐标；位移的 x/y 归一化尺度不同，不能直接按角度旋转未经换算的归一化坐标。各层自身缩放/旋转也随组更新，背景可独立运动。该方法表达二维组运动，不创建复合片段、父子约束或透视。

非等比的细边框需保持宽高基准：当前生成器的缩放关键帧不是对静态 transform 的再次乘算，见 [计划格式](plan-format.md#画面关键帧与缓动)。线条采用独立 scale_x/scale_y 目标值；仅给 uniform_scale 可能丢失细线比例。共同中心运动还需检查中间插值，旋转与缩放变化较大时按几何误差增加采样点，而非只确认首尾重合。

先比较起止构图和主体大小，再安排运动速度。文字先确定停稳后的整句外框、阅读停留和留白；镜头切换后重新检查锚点，不能只验中心或首帧。共享运动须检查中间帧的相对间距，给各层相同参数不自动证明共同移动；缩放时按倍率归一化间距，不用固定像素间距判断。整组运动可按 [局部复合](capabilities.md#composite) 用原生组运动；组与组外曲线视频或人物遮罩并存时，按 [曲线变速](capabilities.md#speed-curve-groups) 和 [人物遮罩绑定](capabilities.md#matting) 的子集，先核单层控制再看层间遮挡。后方被挡的大字只承担层次，前方小字负责信息；平移显露的源裁边用实际观看边界处理。增加关键点可以近似先快后慢，需注明多点线性近似；不能写成已经接入原生三次方缓出。固定轻推进或关键帧数量不是观感合格的证据。

## 三类遮罩不能混用

- **几何蒙版**控制整张素材哪个区域可见，区域内仍带原背景；不等于人物抠像。
- **窗口内移动内容**与**在固定内容上移动窗口**不同。普通画面关键帧移动素材，也可能改变其蒙版的全局位置；它不能保持内容不动而只移动蒙版边界。后者需要动态蒙版接口或剪映内操作。反过来，要让内容在固定窗口里滚动，教程做法是先复合内容与运动、再在外层加固定蒙版；当前复合外层不接受蒙版，改用其他已准入设计或说明缺口。窗口扫过或扩散的快慢由蒙版关键帧间距决定：经过脸或主体时加点放慢，经过空区时拉开间距加快；这是窗口变速，不改素材 speed。
- **字形/材质组内合成**要先明确底色、文字及混合层序。字形内显示画面时，外层底是原片，上层是复合组（正片叠底）；组内从底到顶为不透明黑底、白字、可选有色阴影，字外必须是黑色而不是透明。字形穿越转场选粗笔画字体或用负字距让字连成块，起点保留可读的标题，入场结束后再放大，放大到笔画白区覆盖全画面才交给下一镜头；检查终帧没有残留黑缝或细缝碎洞。用亮度遮罩在两段完整画面之间转场时，一路乘遮罩 M、另一路乘反相 M 再叠加；只给上层设滤色会让遮罩区内两路画面叠成重影，检查转场中段遮罩内只见一路画面。一个 mix_mode 不代表已经构造整个遮罩；当前基础双轨混合模式仅按 [安装内混合子集](capabilities.md#installed-mix) 受限接入，本段字形/组内遮罩结构只作方法原理，尚未完成组合验收。

滤色与正片叠底按颜色通道参与计算，黑/白是各自的中性输入，不是把任意背景变透明的抠像。绿色去饱和再强光只适用于结果接近中灰的特定素材，HSL 和颜色变化也要核实；不能替代通用绿幕抠除。

静态窗口与曲线变速组合时，先确认素材确实无音频流，再按 [曲线变速](capabilities.md#speed-curve) 选择零羽化矩形；动态窗口只按其中的有限 center_x/width 子集与已列出的组组合使用；真实曲线映射端点，编号源帧和中间窗口位置分别核，不能按平均speed写键或由源坐标格式推定插值时钟。窗口控制可见区域，曲线控制源动作快慢，两者各有职责。同源多层不能只凭平均speed相同认定同步，须核源入点、区间、曲线与目标时间映射。对原片内部切点前后分别看脸、手、脚、道具及动作方向；全身景到近景时同一个窗口可能突然截掉信息，先切开重新构图，再决定是否保留窗口。需要观众看清动作结果时恢复完整画面。

## 作用范围与时长

背景模糊挂背景 clip，局部闪白挂目标分区的小片段；独立效果轨会影响其范围内的多层，不能假定只作用某个画中画。clip.effects 覆盖整个片段，局部时段先切片；切片后同步 source_in、关键帧相对时间和其他同源层。透明顶层片段上的转场不会带动下方各层；需要多层一起过渡时，先把相关层复合，或每层分别安排。

用漏光或闪白衔接时，把最亮帧对准切点，让镜头交换藏在亮峰里，只覆盖切点前后的短区间；亮峰没盖住切点就会露出硬切。

成片时长先满足内容、声音和发布目标。未指定长度时，依据有效动作/信息和情绪转折确定能完整表达的范围，并在计划说明依据；不由原素材长度、教程成品长度或特效展示时间推导。用户说太长时优先删除重复动作、冗余铺垫和无新信息的停留，重新组织原素材；不自动加速全片或套固定 30/55/80 秒模板。

音乐主导时先确定 BGM 源段再锁镜头顺序；原声主导时先保留对白语义、打击声和动作结果。原片声音常已混合，抽取音轨不会自动分离音乐、对白和音效。自动点、波形和八拍循环只能提供候选，裁乐句或拼原声仍需正常速度试听；未听不称无缝。

教程示例帧数按项目 fps 换算；先决定要保持相同帧数还是相同屏幕持续时间。静态图像只能证明构图，连续运动与声音效果仍分别核实。非必要效果可用可实现方案；用户明确要求的核心方法缺接口时，准确说明必要缺口，不用滤镜或普通旋转报告同款完成。

文字强调先保证清楚白字与底层对比，再按 [受限放射发光](capabilities.md#glow) 控制光晕。小字在亮背景上加光可能仍难读，优先固定底层或换位置；用有／无光对照看字形和注意力，不按特效强度判断观感改善。
