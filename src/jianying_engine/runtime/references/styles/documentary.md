# 纪录片、纪实与访谈

适用于事实、人物观点、事件过程或观察主导的成片。类型可以有强烈视觉风格；下列取舍依据表达和证据需要，并不规定所有纪录片都必须慢或无特效。

## 片源与证据

区分访谈、现场同期声、观察镜头、档案、补画面、重演和示意资料。为会改变观众理解的画面或话语保留出处及已知时间/地点；将已核实、来源陈述和仍待核实的信息分开。不同时间地点的镜头不能被剪成同一现场的反应、因果或目击证据。

原始记录与已剪成片分别处理。二次剪辑只能据实际取得的内容作判断；找不到前后语境时标明限制，不把剪辑后的短句当成完整原始陈述。重演、示意或资料画面的标识按真实用途保留。

## 语义、节奏与转场

先确定事件/观点线索和能支持它的素材，再选择时间顺序、主题结构或问题推进。访谈剪切保留限定条件、否定、时间范围及必要停顿，不通过拆接改变说话人的意思。观察段根据过程与信息变化决定镜头长度，不套固定“慢纪录片”节奏。

画面切换可用现场细节或相关补画面保持观看连贯。需要声音先入或后延时，使用独立音频轨与准确源入点，并回读同步范围；不能只写“J/L cut”就认定做完。没有独立可用声音时不要暗示完成无损分离。

硬切、景别变化、场景声连接可服务叙事；档案、时间跳跃、章节变化按需要用叠化或其他原生方式。强转场不得让观众误认事实关系，不从漫剪库直接套全程震动、闪白或花字。

## 文字、声音与方法来源

姓名、身份、时间、地点、资料来源及数值标注以已核实内容为准。身份条、对白字幕和章节文字明确分工，出现时长与语义匹配；修饰性动画不抢过证据。资料不够时先剪不依赖该事实的部分，明确必要缺口。

优先听懂采访与现场，保留有表达作用的环境声；音乐可参与情绪，但不掩盖话语或冒充真实现场音。没有实际试听/转写不能宣称对白对齐或语义接剪已经核实。未获得的对白音轨属于剪辑缺口，不能全部推到用户最终检查。

需要标题、资料图排版或照片处理时再查 [教学库](../tutorial-library.md)。该库主要提供视觉方法，不是纪实采访、事实核实或叙事课程；不声称已学习未审过的纪录片教学。

计划与参数回读重点：说话的源范围、语境保留、音画同步、档案和现场区分、文字来源、时间跳转。最终播放和导出由用户完成。
