# 漫剪与节奏混剪

适用于音乐、情绪、角色动作和视觉冲击主导的漫剪；游戏集锦、运动集锦和真人 MV 可借用节奏组织，仍需按各自片源保留关键动作与信息。剧情解释或教程主导的动漫素材转到 [讲解分区](explainer.md)。

制作与修订按[创作决策层](../../guides/planning.md)展开。本页提供镜头与声音的选择条件；后续原生字段、效果和界面边界属于剪映路线。达芬奇与AE按各自指南核对支持，方法可借鉴，能力不互相继承。

## 镜头与音乐如何共同推进

先看选中片段的完整事件，再决定它承担动作、关系、反应、细节或意象的哪一种作用。同一个镜头在不同位置可以改变含义；先理解源语境，再按用户允许的重组范围创作。记录源范围、关键事件与声音证据即可，不给所有素材贴固定情绪标签。

音乐先划出实际有变化的乐句、音色、配器、留白与演唱段，找到画面可以发展或反向对照的位置。镜头密度、源动作速度、景别变化和效果密度分别决定：音乐变密时可以保持一个完整动作，长音也可以承载信息快速累积。高潮可以是一次揭示、完整命中或安静的反应；由前后期待决定力量，而非固定快切。

在关键段落比较下面的候选，按当前素材选择，不把各行串成必用模板：

| 当前表达任务 | 先看什么，再决定怎样剪 | 失效信号与调整 |
|---|---|---|
| 让两个动作接成一股力量 | 比较运动方向、轨迹、速度和相位，试动作中接剪或让下一动作承接上一落点；声音可让接触而非切镜响应重音 | 发力重复、方向混乱或结果未看清时，重选相位/镜头，保留必要准备或结果，不用震动掩盖 |
| 建立对峙、靠近或离开 | 先找视线、相对位置与反应，选择揭示对象、延迟反打或保留空位；按关系变化决定景别 | 只有两张人物特写却无关系依据时，补空间/物件线索，或诚实改为并置联想 |
| 让回忆与当下产生联系 | 找同一物件的不同状态、相近手势、构图或可核实的对白，比较意象硬切、声音先入与局部叠化 | 叠化造成无意义重影、意象未建立时，换关系更清楚的镜头；不从“悲伤”直接推导叠化 |
| 在音乐进入或释放处制造冲击 | 核对前段是否建立期待；比较动作完成、景别骤变、视觉揭示、短暂抽空与原声接触 | 已有密集爆亮或抖动时减少叠加；所有位置同强度时，重设前后反差及恢复，不只加效果 |
| 让情绪持续发展 | 保留有变化的表情、呼吸、环境和关系细节，让停留有新信息；用不同镜头发展意象 | 同一信息反复、人物长时间近静止时删短或换镜；留白不能仅由黑边、小窗或慢速代替 |
| 展示技术风格与视觉系统 | 先设计主视觉、背景、字与图形的职责，明确进入、发展、到位和下一镜接管；按素材建立共同形状/运动语言 | 包装遮掉脸、武器落点或主动作时重排；到位后无推进时缩短；复杂段后给观众重新定位的机会 |

关键连接简记“源事件 → 观众注意与含义 → 选中的剪法及理由 → 当前后端操作”，必要时保留一个被舍弃的候选。这里只是记录判断的方法，不新增JSON字段。动作、视线、空间和构图的通用条件见[画面连接](../general-editing.md#从表达目标到画面连接)；技法的具体组合法见[组合方法](../technique-combinations.md)。

## 片源与段落设计

- 看清角色、动作方向、景别、冷暖变化和原片切点。区分原片自带的震动、闪光、字幕与本次添加的效果；已剪视频的密集内切点也计入观看节奏，不能只计算本计划的剪刀数。
- 优先建立引入、变化、蓄势、爆发、回落等适合当前素材的段落关系，再安排构图、层次、文字、遮幅、运动快慢和转场，不机械套固定段落或逐镜头贴特效。
- “炫酷但不影响观看”要求主体与动作可辨认，不等于极简。强变化后允许完整、清楚的主体画面；保留的长镜头也应有重心发展，不靠持续震动维持热闹。
- 静图或定格需有细节揭示、蓄势或情绪停留的作用，并安排进入与释放。视频源也可能长时间人物近静态；对需要持续推进的动作段，查看首、中、尾及原片内切点，缩短无新信息的停留或换用真正推进的选段，不靠窗口运动冒充人物动作。有活跃背景时区分背景和人物作用范围；整体效果轨可能影响所有层，局部效果优先落在对应片段。
- 时长由有效动作、情绪推进、声音与发布目标决定，不由原素材总长或教程成品决定。用户觉得作品太长时，先删除重复动作、冗余铺垫和无新信息的停留，从原素材重建紧凑段落；不默认加速全片或用固定秒数，不能为了展示更多技法延长作品。

情绪片先找具体关系与重复意象，判断相邻镜头是否延续、对照或改变了它们。按内容选择记忆窗口、景别交接、留白、声音先入/延续或构图展开，让变化有可辨认的起止状态。安静的全屏长镜头也可以完成表达，但“克制”不能成为未设计节奏、排版与声音的理由；窗口和转场同样不是必用配方。

重影、强色块、白场、黑底小窗或黑场短句都只能作为具体语境中的候选：重影需能读出两幅画面的关系，小窗需有缩离前后的构图依据，黑场需让声音或前镜的含义继续。比较直接接剪、停留或声音连接能否更准确地完成同一任务，再决定表现方式及退出后的清晰画面；不固定赋予每种效果一种情绪含义。

采用倒叙或蒙太奇时，重组事件与记忆的出现顺序，不默认倒放镜头动作。可先给结果或关系局部，再用相遇、反应和行动补足动机；交叉段要通过物件、视线、动作或冷暖建立可辨认的联系，并在关键对白和行动时恢复清楚的完整画面。音乐段落决定情绪推进，原片顺序只作素材线索；不把倒叙写成每部 MV 的固定模板。回忆呼应与前后重复播放是两回事，按 [镜头使用与去重](../general-editing.md#镜头使用与去重) 核对。

## 技术流组合

用户需要画中画、关键帧、蒙版等整体表现时，读 [跨教程组合方法](../technique-combinations.md)，按段落确定主动作、背景、局部窗口、文字和强调层的职责，再选具体方法：[分层揭示](../layered-reveal.md) 补分区与遮挡，[文字融景](../text-in-scene.md) 与 [主体与图形穿插](../subject-graphic-interleave.md) 补前景与运动，[节拍卡点](../beat-marking.md) 补声音驱动；不把任何一位作者的作品作为全片模板。

同源层先核对源时间、构图和缩放，再安排错开入场与局部变化；分屏完成后及时回到可辨认的主动作。滤镜和闪白加强设计，不能替代层序、窗口或运动。前景缺失、动态蒙版或透视接口缺失时明确记录，普通原画面板与二维移动不得报告成人物抠像或三维复刻。

文案、排版与技术展示分别判断；类似修订读 [剪辑修订与表达判断](../creative-review.md)。保留明确认可的内容，画面强变化后交还完整动作，认可不提升为兼容、试听或导出验收。

## 文字作为画面元素

区分对白字幕与装饰文字：对白仍按语义可读；装饰文字先确定在构图中承担背景材质、空间层、分区边界或随主体运动的标记，再选择字形、位置、配色与运动。文字显现、擦除、消散可辅助，不默认把融景等同于短词加动画。针对空间、复合运动与蒙版揭示读 [文字融景](../text-in-scene.md)，再查询实际资源枚举。

具体排版按 [从句子到可执行排版](../text-in-scene.md#从句子到可执行排版) 先安排最终阅读构图，再设计进入和退场。对白、作者文案及背景字可采用不同层级；沿窗口边界、视线方向或场景留白选择锚点，核对动态背景中的对比、换行和阅读时间。统一居中、底部贴字、低透明度或套淡化动画本身不构成融景。

巨字和海报不是必用模板。需要海报时设计它与人物、图形和转场的关系；普通大字直接覆盖脸部、固定竖排与重复英文会显得贴图。竖排只用于短词，并且画面留白或主体方向本身是纵向的；长句保持横排。编辑设计型包装要成系统：定一组主色和一种边线或框架规则，编号、短标签等信息块固定位置和留白并跨章节复用，字号分大标题、副标题、小标签三级；日期、编号、双语、署名只在建立主题或章节结构时加入。装饰短字先尝试透明叠字与场景留白；底板只在阅读对比、信息分区或遮挡转场确有作用时加入，并核对面积、位置及动作遮挡。不要只为展示组运动给单字加厚重整块底板；字与板共同移动不自动构成融景。文字进入后应有合适的停留与退场，不凭“动画已写入”认定融入成功。多个文字层和声音起点要相互配合。

文案先确定该段要表达的动作、情绪或主题，再决定是否需要文字；文字不能只为填满构图而存在。对白、引文与作者新增文案分开，未核实的人物设定、剧情和台词不要补写。诗性表达可以使用，但要有镜头依据和具体意味，不为古风、对仗或字数拼出空泛短句。开头提出的意象或悬念应在后段发展或回应；没有后文作用的句子改写或删去，再安排字体和动效。

短字、留白和动画都不是通用文字方案；按内容设计层序、方向及共同运动中心。

真实人物遮挡需人物前景；矩形面板压住一部分字不等于人物抠像。字形画面、文字蒙版、复合片段或跟踪超出当前接口时说明缺口，不用外部渲染替代。可实现的原生文字样式、层序与运动见 [原生效果](../native-effects.md)。

### 歌词与对白分工

带演唱的 MV 先判断歌词怎样参与情绪与叙事；用户要求歌词时，不用作者文案或对白字幕冒充。区分歌词、对白、标题和作者新增文案，歌词跟乐句、对白跟人物发言；重叠时明确阅读主次，必要时错开装饰文字，不能为让字齐出而错移歌词或对白。

歌词来源与字幕点位分别核实：已核实歌词不等于对齐本地音轨；同名歌曲、原唱文本或网上 LRC 不证明本地版本时码一致。依据所用音频的乐句校对起止，不能直接继承平台时码。只有关键短摘录时明确范围，不能交付为全曲歌词；识别、听辨或全文获取有缺口时照实记录，不编文本或精确点位。

歌词沿用 [融景排版](../text-in-scene.md#从句子到可执行排版) 的锚点、对比与阅读停留；不把满屏字或逐字跳动当成 MV 的必要形式。

## 空间与整段动效

参考 [主体与图形穿插](../subject-graphic-interleave.md)，先检查主体能否与背景分离，再设计完整人物、前景图形和局部人物的穿插关系。普通原画的区域蒙版会携带原背景，不等于透明人物；现成动态图形素材的内部运动也不等于剪映原生可调几何动画。

为段落设计可辨认的起止构图：画外入场、到位缓出、主体清楚展示、背景继续运动、构图尺度转换。主体组内部保持相对关系，背景空间层按需要独立运动；不能要求全体层同速同比例后声称视差，也不能仅凭 3% 左右推进或几个文字动画判定观感完成。静态关键帧回读与用户观看反馈分别记录。

文字改善而整体观感仍不足时，重审主体、图形与镜头状态变化；不要继续只给文字加效果。

## 转场与冲击

硬切适合动作接点和重音；景别、情绪、空间或构图明显变化时主动设计连接。先看动作方向、遮挡、颜色和视觉重心，再考虑推拉、方向擦除、分割、溶解等原生转场；扫块或短特效与原生转场分别记录，不把一个扫块当作已经完成全段衔接。

只有震动能明确表达接触、冲击或情绪变化时才使用，并按动作辨识和音乐证据调整强度、速度、持续时间及出现间隔；单独卡到音乐点不证明震动有必要。发现持续抖动或高频闪动看不清时，先查原片、循环动画、关键帧和作用范围，再调整干扰源；原片已有密集刀光、雷光或爆亮时尤其避免叠加闪白，优先用方向交接、分区显现与构图回收表达节奏。不以叠加更多模糊或闪光补救。没有统一的转场数量、抖动频率或效果秒数；全程摇晃与强闪不应取代段落设计。

## 声音与方法来源

有可靠音频证据时按乐句、重音与情绪推进组织画面。波形幅度起音只是候选，不等于音乐节拍；未试听不得宣称精准卡点。原片已混合音乐、对白和音效时检查是否会与新增配乐打架，不声称可无损分离。

### BGM 与原声并置

BGM 负责连续的段落、情绪和主节拍；原声补充局部信息和触感。节奏主导、仅叠加短人声或打击事件时，优先保持 BGM 乐句与节拍连续有力，通过原声选段、增益及自然留白配合，避免为保留混合原声而长段或深幅压低 BGM；必要避让按事件与听感决定，不设通用音量配方。后续打戏优先评估招式名称、短对白、刀剑碰撞、命中、落地、蓄力和爆发声，只保留有作用的事件。招式名保留完整词句，碰撞保留起音和必要余音，避免为卡点截断语义或动作因果。

情绪 MV 在决定全片静音前，评估相遇、犹豫、呼喊、应答、呼吸和环境声能否建立关系或形成转折。适合保留的对白先保证完整语义、应答与必要停顿，再安排 BGM 避让及前后镜头；需要时让原声先入或延续，但维持源时间与声画关系。没有合适原声时纯音乐成立，不能只因类型叫 MV 就删除全部声音。

镜头有明显交谈且关系由对白推动时，优先保留同步原声；若该段确实只需音乐，改选非发言的动作或反应，避免长时间出现张口说话而听不到回应。口型对应的画面保持原速或经实际核实的同步映射，不能给画面变速却沿用原速台词。对白叙事主导且需要 BGM 避让时，在完整问答与必要句间停顿中保持一致的避让，待对白和余音结束再平滑回升，不在每句间突然抬高；幅度按原声残留与听感调整。

先确定原声事件的源时间、动作接触/完成时刻与 BGM 重音的关系，再决定切镜、构图到位或局部强调。可以让招式名进入音乐留白、碰撞与重音重合，也可用原声独立形成节奏；不要求每个事件都落在音乐波峰，更不为凑拍把碰撞声移离实际接触点。

把选中的原声事件提取为独立音频片段，保留来源与源时间；使用已有 audio 字段裁切、调增益及淡入淡出。视频内仍有同一声音时静音或减掉重复路径，避免双重播放。需要 BGM 避让时可按区间拆段调整 volume，或用 audio.keyframes 写明确的线性增益包络，并保持源段连续；淡入淡出须避免削掉碰撞起音。关键帧不等于自动 ducking；**剪映原生**的自动避让与算法分离仍未接入，不猜字段或宣称已自动完成——需要包络或 stem 时用 [离线自动闪避](../capabilities.md#ducking) 与 [离线人声分离](../capabilities.md#separation)（自备权重），产物仍只是关键帧与普通素材。时间映射与参数范围见 [音量关键帧](../capabilities.md#audio-keyframes)。

对白配合新 BGM 时，优先使用可靠的纯对白声部；多声道的中央声道可作候选，但仍可能带配乐、混响和环境声，不能称为“仅保留人声”或算法分离完成。原片自带音乐无法可靠分离时，选较干净的事件、调整方案或沿用用户接受的缺口，并说明混合音轨限制。不要整段原声和 BGM 同音量铺满，也不设通用增益、提前量或原声数量。正常速度试听检查招式名清楚、声画同步、撞击有力度、BGM 不被遮蔽及叠加峰值；未试听时保留未核实状态。

没有可用监听或转写能力时，保留源范围明确的原声候选并标注语义/听感未核实；文件名不能作为台词原文。不得编造对白字幕或把选定范围称为完整句子。增益包络、同步映射及采样峰值检查只证明各自技术结果，不能证明对白可懂、原片配乐不冲突或卡点准确。

音乐主导时，在锁定镜头顺序和高潮前确定所用音轨源段，按 [节拍卡点与按拍分层卡](../beat-marking.md) 复核自动候选与密集节奏。临时降速只为辨认，完成后恢复目标速度；音乐点可对应动作完成、构图到位或分层显现，不必每拍切镜。作者建议的略早显现按实际观感试调，不统一套固定提前量。点位与音乐段落依据保存在任务分析，缺少试听时如实标为未核实。

先从当前动作、情绪、意象和声音设计构图与段落；需要原理或操作依据时查 [组合方法](../technique-combinations.md#按目标检索) 与 [渐进分屏](../layered-reveal.md#split)。无需找到同款配方，不能把教程的巨字或示例秒数直接搬过来。游戏片保留影响判断的 HUD、战斗结果，运动片保留动作完成和落点；是否裁掉或隐藏由成片目标决定。

计划与参数回读重点：主体画面连续、效果作用范围、文字与动作时间、转场挂载和持续时间。实际观看效果仍由用户最终检查。

## 反馈与修订

用户反馈抖动、贴字、硬切或文案不足时，先定位片源及本次操作的作用，再按 [修订判断](../creative-review.md) 调整。转场、遮挡扫块与短时强调分别核对，不以数量判断连贯性。保留明确认可范围，从原素材另存版本；兼容和播放证据分别记录。
