# 商业展示、产品与品牌宣传

适用于产品识别、功能展示、品牌情绪或明确传播目标主导的成片。人物实拍、静物、动画与屏录可以混用，片源画风不单独决定剪辑类型。

## 目标与片源

先识别具体产品、传播重点、已有品牌规范和用户明确的行动目标；单纯品牌形象片不强加价格与购买按钮。产品缺失或关键功能没有实际素材时说明缺口，不用相似库存镜头冒充用户产品。

区分真实功能演示、使用场景、包装/标识细节、氛围素材和示意动画。颜色、比例、产品名称、规格、效果对比及数值按已提供和可核实的资料处理；没有证据的使用效果不能靠剪辑暗示已证明。

## 节奏、文字与转场

按实际传播目标组织吸引注意、识别、重点展示和收尾，可有不同顺序，不机械套同一广告模板。产品首次识别、功能发生和展示结果留出看清的时间；情绪段可快，关键卖点不做无法阅读的闪片。

文字按品牌标题、卖点说明、必要标注区分，遵守已给品牌样式并避开标识和功能区域。文字可与镜头融合，但关键产品信息的阅读优先级高于装饰动画；默认字体与当前接口不足以实现指定品牌字体时说明限制。

转场依据产品轮廓、动作、色彩或场景设计；平稳展示、运动品牌和科技片可有不同强度。借用 [节奏混剪](anime-mix.md) 的冲击方式时仍保持产品细节可辨认，不把炫酷当成所有商品的统一要求。

## 声音与方法来源

解说、产品操作声、音乐分别按用途安排，保留能说明体验的真实声音；设计音效不能被当作产品实测性能。会员效果已授权，但外购音乐、模板、字体或其他新增费用仍按主 Skill 的授权范围处理。

先根据产品与传播目标自行设计镜头、文字和声音；需要具体实现依据时再从 [教学库](../tutorial-library.md) 检索人物介绍、产品细节、遮挡或排版方法。计划与参数回读重点：产品身份、关键展示范围、重要文字停留、音量关系及素材来源。最终视听检查与导出由用户完成。
