# 原生后台静帧预览

2026-10-08接入可选 `editor.py native-preview`，使用剪映11.5.0.14471随安装提供的正常N-API播放器。它可核对指定时刻的局部画面，不启动或操作剪映界面。普通剪辑的最终完整视听检查和成片导出仍由用户完成，不把预览作为所有交付的新增关卡。

```powershell
& $skillPython "$skillRoot\scripts\editor.py" native-preview `
  --install '本机已验证的11.5安装目录' `
  --draft '当前新建草稿的绝对路径\draft_content.json' `
  --out '不存在的独立预览目录' --times 0.5 1.2
```

只接收明文生成稿及1–8个有限、处于草稿内部的秒数；当前输出固定320×180 RGBA静帧，适合局部构图/运动检查，不用于细边缘、高清质量或完整时序验收。细边缘研究须先用横、纵一像素见证图证明有效采样：只扩大readFrame包可能仍是低分辨率放大，需同时核对正常加载的渲染尺寸。研究包装器测成更大静帧不自动扩大正式入口；单像素跳变的交点插值宽度也不能称为柔边。保存后的加密稿不由此命令回写或解密：入口先按字节判定明文/加密/损坏/缺失，加密稿具名拒绝且不进解析（自检 `scripts/draft_state_self_check.py`）。原生资源下载、会员认证和资源缺失不由脚本解决；有图像包也不代表其内容或全部效果正确，仍需实际查看选中帧。缺失本地视音频、异常帧率/时长、越界采样或已有输出目录直接拒绝。

脚本先校验 `assets/native-preview-<安装版本>.json` 中两份N-API模块、vm_sdk.dll及服务/预加载脚本的SHA256；按 `--install` 目录名自动选择对应清单，没有清单或字节变化时拒绝运行，迁移须重新验证。现有清单：`native-preview-11.5.0.14471.json`、`native-preview-11.6.0.14552.json`（11.6 实测 2026-10-16）。默认采用当前安装内的bun.exe，11.6 实际发布为 `vebun.exe`（Bun 1.3.14-canary.1，原文件名 bun.exe），缺失时自动回退；同机Node也经过实测，可显式指定其绝对路径，不能把未知运行时视为已兼容。仅在子进程环境中加入安装及vm_sdk的DLL搜索目录，不修改用户PATH或剪映设置。

含草稿内本地字体的稿还须有生成清单`_skill_manifest.json`。预检核对manifest字体清单与`Resources/local-fonts/`文件身份，并确认文字材料顶层`font_path`、富文本style的`font.path`为空ID绑定且都指向草稿内相同文件；不读取或要求原字体路径仍存在。

播放器在独立工作目录载入草稿副本，通过create/load/seek/refresh/readFrame获取VEF1包。回读包头、尺寸、长度及实际帧时间戳；允许一帧量化误差，拒绝旧位置的残留帧，并要求时间戳合格的RGBA帧连续三次完全一致后才接受，以覆盖合成层尚未刷新但时间戳已更新的情况。`preview.json`记录请求、实际时间、原生PNG身份、进程、清理与错误，源草稿字节必须保持不变。PNG只解码原生帧，不外部重做视觉效果。

时间戳正确仍可能遇到画面残留或合成层未就绪。声明局部画面通过前须实际看像素，核对源场景、文字与叠加层；不同位置异常重复或缺层时该样本不准入。可在任务隔离的预览包装器中尝试独立会话、加载/seek后短等待及再次refresh，并保留过程；成功只证明本次样本，不能记成共享工具已修复。单次预览缺失某效果也不足以判定整个剪映不支持它。


退出遵循安装内服务的真实调用链：销毁会话、addon.shutdown，再调用其导出的 `requestVideoEditorServiceSelfTermination(agent_runtime_addon.terminateProcess)`。仅结束脚本创建的工作进程；不注入宿主、不关闭用户的剪映。它是清理后的受控自终止，不证明全部原生线程自然退出。返回码0还须同时满足完成检查点及全部有效帧；超时由监督器仅终止自己创建的子进程，并判本次失败，不能记作正常退出。

已核实运行时支持本机 Bun/Node 的指定静帧；零返回码但内部失败、过期帧或超时均拒绝准入，输出须实际看像素。本项目仍记录自身结果。

这项能力不包含音频监听/后台PCM导出，不提供跟踪、抠像、倒放或分离算法的离线任务提交、进度、真实取消。安装内job包装器的AbortSignal检查不能替代算法引擎取消。算法模型和配置文件存在不等于已有执行入口；高级算法继续按后台验证清单的暂存状态处理。
