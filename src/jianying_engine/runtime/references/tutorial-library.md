## 从方法到作品的调用

先按当前段落的视觉问题选方法，再核对素材前提和所选后端的准入；不按教程列表逐项凑效果。分屏要说明怎样形成与接管，成组运动要说明共同中心和到位状态，动作卡点要说明哪个事件响应声音。方法描述、后端能执行、当前作品实际采用、用户认可分别保留证据。

技术流的设计与实际短段复核走[创作决策第5–6步](../guides/planning.md#5-把技巧变成适量且可执行的表现)，用户反馈与跨任务复用走[短段比较与反馈积累](creative-review.md#短段比较与反馈积累)。新增教程先补当前真实缺口；没有原生实践和作品结果，不把笔记增加量当作能力升级。

不依赖抠像的技术流也可按下面的问题组织，不必退回相框与小幅推进：

| 连接问题 | 已有方法入口 | 检查重点 |
|---|---|---|
| 全画幅镜头需要方向和速度交接 | [节拍与尺度冲击](beat-marking.md#对-bgm-剪辑流程的补充)、普通位置/缩放/旋转关键帧 | 入画、到位和出画速度不同；切点接住观看重心；放大/旋转留足边缘 |
| 希望动作有加速与释放 | [静音视频曲线变速](capabilities.md#speed-curve)或原生固定变速 | 源范围和声音政策明确；曲线和其他表现只按准入组合，不临时剥音轨绕过检查 |
| 一幅画面应成为下一镜的过渡载体 | [局部复合](capabilities.md#composite)、[角点透视](capabilities.md#perspective) | 视频和字按共同中心运动；整幅画面缩退/折角/退出，下一镜能连续接管；二维投影不叫三维摄像机 |
| 窗口出现但缺乏推进 | [分层补齐](layered-reveal.md#reveal)和[渐进分屏](layered-reveal.md#split) | 以短时积累、主次变换、展开和释放连成过程；不能堆完小窗后长时间停着 |

先回看原始教学画面再选方法。历史研究目录可能已迁移或清理视频，仅留联系表和出处；检索到文字笔记不能宣称本轮重看了视频，保留的离散采样也不等于连续观片。来源定位及实际复核范围记录在本次项目外维护证据中。
