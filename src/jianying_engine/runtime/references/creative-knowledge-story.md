# 剧情、情绪与结构：决策知识

适用剧情短片、动漫/游戏剧情重组，以及需要观众理解事件变化的作品。音乐展示、纪实或信息视频可以只取相关方法；不要把每个任务强塞进同一种剧情结构。创作流程总入口见 [规划](../guides/planning.md)，已有类型方法见 [通用剪辑](general-editing.md) 和 [漫剪](styles/anime-mix.md)。

## 从素材建立可核对的故事

先对候选片段及相邻范围看连续事件、听必要对白与声音；提取人物、事件、环境和源时间。不同证据分别记为：看见/听见的事实、由画面推断的关系、尚未听懂或未验证的部分。自动转写只能提供候选，截图不能证明动作与声音；无法取得关键证据时先保留缺口，不编台词或原因。

剧情向任务可用下面几个问题检查信息是否真正出现在作品里，不要求每个问题都用字幕解释：

| 问题 | 观众需要得到的线索 | 常见失败与改法 |
|---|---|---|
| 谁在行动、想得到什么 | 人物选择、对白、物件或具体行动 | 只看到关系镜头却不知道人物想做什么：回源找能表达目标的行为或完整对白 |
| 什么阻碍了他、代价是什么 | 具体障碍、规则被体验到的结果或可核对对白 | 只有空镜和紧张音乐：补能理解障碍的事件，不凭通用常识替原片补设定 |
| 为什么接下来要行动 | 触发事件、收到的信息、人物反应 | 两场景并列但没有因果：增加必要的触发或反应；不把不同时发生的事件剪成事实因果 |
| 选择造成了什么变化 | 行动结果、对方反应、关系或处境变化 | 连续展示“寻找”却不给结果：保留结果与反应，再决定结束点 |
| 哪些信息故意晚一点揭示 | 冷开场的问题、回忆与当前的区分线索 | 过早显示同一结果或反复回放同一动作：换不重复的线索并核对用户的重复限制 |

镜头可以承担交代、提问、反应、对照、转折或余韵。一个段落如果只有风景与相似表情，且没有新增关系或信息，需要重选事件，而非默认添加字幕、转场或慢动作。

## 可比较的结构选择

1. **目标→行动→后果**：适合观众先需要理解任务与代价。先建立人物的选择，再用反应、变化或环境兑现后果；缺少必要素材时降低叙事主张。
2. **结果或悬念先行→回到原因→再次抵达结果**：开场只提出可辨认的问题；回忆提供观众理解所需的原因。结尾用新信息改变开场含义，避免只是提前播放同一个高潮再重播。
3. **双线交替**：先给两边各自的位置、角色或时间线索；每次切换回答一个共同问题或形成对照。非同期素材可作为回忆/联想，但不能默认真实同时发生。
4. **物件与关系发展**：以已出现的同一物件、动作或构图联系不同阶段；每次出现应改变人物关系或信息。换景别和动作阶段，不以同一段画面反复播放冒充发展。

这些是候选而非模板。对关键连接比较两个有本质差异的方案，例如“先给反应再解释”与“先给原因再反应”；根据实际素材、语义和时长选一个。声音尚未取得且需要比较连接时，优先用已确认的画面动作、结果或反应形成可执行备选；声桥仍可作为待听证的选择，但不要把未经确认的声音当成唯一备选。要让观众看清一个行动的准备、触发或结果时，不为追求快而把因果切断。

## 失败案例抽象：有动作，没有剧情

一次用户否定的短段把两次人物互动连在一起，并使用声画错位、画面展开和轻推；用户反馈仍然平淡、看不出剧情。该反馈只说明该版本未达要求，不能推导所有克制剪法都无效。

下一次遇到同类反馈，先检查：是否缺少目标/障碍/选择/结果，是否保留了可听懂的关键对白与反应，动作呼应是否改变观众理解，再决定是否需要新的表现。为两段完整场景各加运动或过渡，不自动补出缺失的事件因果。用户已否定版本只作对照，不当认可基线；具体文件和评价留在原项目记录。

## 决策的最小产物

在现有项目计划或 notes 中保留：作品希望观众理解的变化、支撑它的源段与声音、尚未确认的关键事实、拟采用的信息顺序和结尾。创作可以自主完成；这些记录是方便后续执行与复核，不是要求用户填写表格。
