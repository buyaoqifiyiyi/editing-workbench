# 创作决策与任务分流指南

制作任何剪辑项目前、需求大改时或收到审美反馈时，先按本指南明确表达主张、选段逻辑与后端分工，再进入具体参数编写。

## 后端职责分工

OpenEdit Engine 采用纯开源多核协同架构，无商业版授权限制：

- **FilmCraft（主剪辑 / 调色 / 字幕 / 导出）**：承接多轨 V/A 时间轴、硬切与转场、变速/倒放、Lumetri 曲线/色轮/HSL/LUT、26 种混合模式、富文本多色重点词高亮与烧录字幕、OTIO/FCPXML 交换与 H.264/HEVC/ProRes 导出。
- **EffectCraft（高级动效 / 特效 / 透明叠层）**：当仅用 FilmCraft 基础运动/调色不足以完成高级文字动画、图层样式、复杂遮罩、表达式或 3D 合成时，通过 `overlays[]` / `render-overlay` 输出 **ProRes 4444 RGBA (.mov)** 叠层自动合入主时间轴，或通过 `effectcraft-exec` 直通调用。
- **FFmpeg 与离线 AI 工具（白名单辅助）**：`inspect` / `normalize-media` 处理 VFR 转码与流探测；`auto-cut` / `rough-cut` / `auto-reframe` / `matting` / `audio-master` / `beats` / `ducking` / `transcribe` / `separate` / `denoise-audio` / `tracking` 仅按具体需要调用（支持 `--gpu` CUDA 加速与 `--draft` 半分辨率快审），不为了堆技术而强制启用。

## 创作判断流程

### 每版同时设计剧情与剪辑

1. **明确观众要看见与感受到什么**：用 1–2 句话确定本次核心主张、必须保留的人物动作/对白/信息与交付目标；如果只要求给修改意见或拆解脚本，只输出文本建议，不强行新建工程目录。
2. **检索已学剪辑知识**：制作前根据当前难点用 `search_knowledge` / `openedit knowledge` 查询创作知识库（如围绕“叙事主线与人物动机断层”、“声桥先入或延续”、“画中画重复如何全画幅接管”、“对白与配乐混音如何人声分离”等检索具体方法），通过 `read_guide` / `openedit guide` 精读对应章节后再落参数。
3. **选段与因果推进**：先选动作发起、接触、反应与结果都完整的真实源区间；去重检查源时间范围与画面相似镜头，不以镜像/缩放替代镜头推进。
4. **声画协同（先听觉连续，再画面接管）**：声音不能被粗暴硬切；按需要安排声桥衔接（声音提前入画或声音延续到下一镜头），背景音乐与对白并用时先核响度主次并用 `ducking` 做自然让位。
5. **构图、文字与变化克制**：确定每一帧的唯一视觉重心与留白；标题/高亮字幕停稳后才给足阅读时间；特效与透明叠层必须服务内容转折与节奏呼吸，不用“数量多”掩盖结构平淡。

## 交付与两类验收分离

向用户汇报成果时，务必明确区分以下两项：

1. **内容与视听表达层面**：实际取舍了哪些镜头、为何在此处切镜或安排声桥、调色与重点词高亮、预计观众体验以及仍待确认的观感/节奏问题。
2. **技术验证层面**：诚实列明实际执行成功的检查层级（`validate`、`build`、`preview` 静帧视觉核对、`ffmpeg -v error -xerror` 全解码），严禁把自动化构筑通过描述为“已人工连续看片并保证审美无误”。
