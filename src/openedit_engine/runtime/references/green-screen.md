# 绿幕与色度抠除：跨类型的合成方法

## 选型依据

绿幕是准备可分离前景的一种方法，色度抠除是按颜色去除背景的操作。它们属于跨影片类型的共同技法，按素材条件和合成目的选用，不归漫剪专属，也不要求每种影片都用。绿色、蓝色及其他合适的单色背景都可作为取色对象；背景色不能与要保留的主体颜色混淆。

先区分三种素材：

| 素材条件 | 处理选择 | 关键判断 |
|---|---|---|
| 已有相对均匀的单色背景 | 原生色度抠除；必要时结合静态蒙版排除无关区域 | 主体有同色衣物、道具、反光时会误抠除；背景阴影、色差、压缩及运动模糊会影响边缘 |
| 已有透明通道的原素材 | 直接作为透明前景叠加 | 实际检查透明区域；不能从 `.mov` 等扩展名推断必有透明通道 |
| 普通复杂背景影片 | 先用 `openedit matting` 离线 AI 抠像生成 ProRes 4444 RGBA 透明前景，再合入多轨穿插 | 受遮挡、快速运动模糊及发丝细边影响，须按黑/灰/白三底及实际背景多帧实看检查；单色键不能用于复杂背景 |

如果参与拍摄，先按主体衣物、产品、道具选幕色，尽量保持幕面照明均匀、主体与幕分开，减少投影和反射染色。后期提高强度不能自动补救差的原素材。已有片源则按实际条件挑选镜头或分段处理，不假定它可重新拍摄。要让物体从屏幕或道具里出现、或被替换时，优先用同机位、同光线的两次实拍提供真实运动：在手势接触或停顿的瞬间切换，对齐物体的大小、位置和角度，保留真实投影；只能用缩放动画替代时说明差异。

- 动态环形图形另有白色背景，单独取白色；00:38 所见强度为 23。色键不只限于绿色。不要对整组人物和图形统一抠除白色，否则人物的白发、白衣也可能被抠除。

## 跨类型应用

| 成片类型 | 适用目的 | 保留的表达重点 |
|---|---|---|
| 漫剪／节奏混剪 | 主体与字、动态图形前后穿插；主体组入场；背景独立运动 | 动作、眼神和关键姿态清楚；不能用持续抖动掩盖层次缺失 |
| Vlog／旅行／生活记录 | 人物与地图、地点标题、示意画面组合；局部屏幕内容替换 | 合成服务经历与地点表达，保留人物体验和自然声音；复杂现场素材先判断是否可分离 |
| 讲解／教程 | 主讲人与演示画面、图表、步骤同屏 | 信息可读、指示位置准确，给讲解与演示足够时间 |
| 纪录片／纪实 | 棚拍讲解与资料图、说明性示意组合 | 保留来源和事实语境；重建或示意需清楚标识，不能让合成暗示人物当时身处另一现场 |
| 商业／产品展示 | 产品换背景、屏幕替换、品牌图形与产品穿插 | 产品颜色、轮廓、标识、反光和功能展示准确；主体含幕色时先换策略 |

## 原生执行顺序

1. 写清背景、完整前景、图形、局部前景的层序，以及各层是否已有透明区域。确定合成是换背景、同屏展示还是穿插，不先堆效果。
2. 查看拟用范围的起点、终点及代表性运动画面，检查幕色变化、发丝、半透明物、主体同色区域与反光。必要时分片设置不同色键；不能以一帧干净推定全段干净。
3. 从实际背景取代表色。先用足够去除背景的较低强度，再检查主体是否出现洞、边缘收缩、残底或闪烁；逐项调整，不照搬教程 63、23 或接口默认 20。静态蒙版只用于适合的固定区域，不能冒充动态轮廓抠像。
4. 前景分离后再匹配背景的比例、位置、透视线索、亮度与必要的原生阴影。色键只提供透明区域，不自动完成透视、跟踪、立体感或运动。
5. 做前后穿插时复制同源前景，保持源范围、时间、速度、位置和缩放一致，再决定上层保留的局部。局部前景随动作不再适合固定蒙版时，重新选镜头或使用可执行的原生抠像方式。
6. 设计明确的运动状态：画外入场、到位、留出观看时间、背景变化、退出。组内保持关系，背景可以独立运动；抠干净的人物加静态大字仍不等于空间动效完成。若前景与底层需要整组协同缩放、旋转与遮罩裁剪，可用 [混合模式与合成](capabilities.md#filmcraft-blend) 中的 `composites[]` 将相关轨打包为嵌套序列统一控制，或使用 EffectCraft 生成带完整 Alpha 的 `ProRes 4444 RGBA` 前景叠层。后方大字被遮挡时只承担层次，另设前方清楚小字负责信息；用前后层序对照检查脸部与重要动作，再核背景组中间状态。

复杂背景人物先检查完整选区，再处理边缘，最后检查运动中的稳定性。脸、头发、手臂或道具存在大块漏选时先补选区或换镜头；羽化只改边缘过渡，不能恢复被挖掉的主体。黑、灰、白底分别暴露亮边/残片、轮廓和漏选，随后换目标背景复核；不能用近似底色掩盖缺陷。游戏与真人按实际样本分别评估，起中尾静帧不能证明全段无闪烁、运动模糊或遮挡恢复合格。

复杂背景补选前对照原画面：花枝、道具等前景遮住人物时，遮挡区域没有可见人物像素；擦掉遮挡物会留下透明缺口，笔刷只能选择现有像素，不能恢复隐蔽的头发或身体。需要完整轮廓时优先改选无遮挡范围；需要保留遮挡关系时把遮挡物纳入创作判断并另验，不能把其残留称作干净人物抠像。连续补选不改善这一输入条件时停止细修，保留失败证据。

有实际alpha序列时，用相邻差异定位需要加看的时刻；先核源时间、切镜、主体运动与遮罩尺寸变化，再对照原画面和合成检查。无运动补偿或真实标注时，MAE/IoU只作候选指标，不当闪烁程度、准确率或质量评分；变化小仍须拒绝固定孔洞、漏选和背景残片。主体完整、边缘、时间稳定性依次过关后才设计人物穿插，不外部平滑alpha冒充原生补边。

## 当前开源接口与执行边界

目前 `openedit-engine` 通过 FilmCraft 原生 `ultra_key`（默认，专业绿幕/蓝幕及溢色抑制）与 `color_key` 完整支持 `clips[].chroma` 连续参数抠像，并可与同片段 `mask`（静态及关键帧几何蒙版）、`fit`、`transform.flip_*` 及 `composites[]` 自由组合，详细参数见 [计划格式](plan-format.md) 与 [纯开源手法映射](recipes.md)。

| 计划字段（`clips[].chroma`） | 开源 FilmCraft 对应含义 |
|---|---|
| `method` | `"ultra_key"`（默认，专业键控）或 `"color_key"`（简单单色键） |
| `key_color` / `color` | `#RRGGBB` 实际背景取色 |
| `tolerance` / `strength` | 容差阈值（`ultra_key` `0..100`；`color_key` `0..255`） |
| `choke` / `soften` / `feather` | 收缩边缘（`0..100`）与柔化/羽化程度 |
| `spill` / `spill_luma` / `desaturate` | `ultra_key` 专用抑色与去溢色控制（`0..100`） |
| `setting` / `output` | `Default|Relaxed|Aggressive|Custom`；输出模式 `Composite|Alpha Channel|Color Channel` |

纯开源后端无商业宿主曾存在的会员锁、离散参数白名单或分辨率限制；上述字段能真实写入 `.fcproj` 并参与预览与成片渲染。但边缘干净度、半透明发丝及反光仍高度依赖原拍摄光线与幕面均匀度，必须结合多时刻 `preview` 抽帧与最终播放实测核查；对于**非单色复杂背景**的人像/前景分离，现在可直接通过 `openedit matting` 离线 AI 抠像生成带直通道 Alpha 的 `ProRes 4444 RGBA` `.mov`（`yuva444p12le`）后再合入 FilmCraft V2+ 轨道。

### 非绿幕复杂背景离线 AI 抠像（`openedit matting`）

- **命令入口**：`openedit matting --input <前景视频或图片> --out <新目录> [--backend auto|matanyone2|rvm|birefnet|rmbg] [--device auto|cpu|cuda] [--gpu] [--model <path>] [--mask <seed.png>] [--decontaminate] [--start 0 --duration 5] [--alpha-feather 0.5] [--keep-audio]`
- **模型自动发现与 GPU 加速**：`auto` / `birefnet` 自动扫描 `%LOCALAPPDATA%\OpenEditTools\models\matting\` 并默认选用 MIT `BiRefNet`；`--backend rvm` 扫描 `models\matting\rvm\`（或指定 `--model`）启用 RVM 时域视频抠像；`--backend matanyone2` 调用隔离 `OpenEditTools\venvs\matanyone2` CUDA 环境执行跨帧记忆传播抠像（未传 `--mask` 时自动用本地 BiRefNet 在第 0 帧生成 `seed_mask.png`，可叠加 `--decontaminate` 消除半透明边缘底色溢色）。
- **输出**：视频默认输出锁定格式的 `matte.mov`（`prores_ks 4444`, `yuva444p12le`, `has_alpha: true` + `ffmpeg -v error -xerror` 全解码验证）及 `preview_rgba.png` / `preview_alpha.png` / `matting-report.json`；图片模式输出 `matte_rgba.png` 与 `matte_alpha.png`。
- **模型兼容与许可证边界**：
  - **MatAnyone 2**（`matanyone2.pth`，CVPR 2026 记忆传播视频抠像，真人和动漫通用）：**NTU S-Lab License 1.0（默认仅限非商业用途**；商业交付或分发须联系作者获取书面授权）。
  - **RVM ONNX**（`rvm_*.onnx`，6 输入含周期状态 `r1i..r4i`）：**GPL-3.0**，逐帧保持时间隐藏状态，适合真人人像视频高速时域抠像（支持 CPU 与 CUDA/DirectML 加速，可配 `--use-model-fgr` 自动前景去色溢）。
  - **BiRefNet ONNX**（`birefnet_lite.onnx` / `birefnet_lite_fp16.onnx`，ImageNet 归一化）：**MIT**，适合商用工程与高精度单帧分离（加 `--decontaminate` 可轻量化去除半透明边缘溢色）。
  - **BRIA RMBG-1.4 ONNX**（`rmbg14_quantized.onnx`）：**仅限非商业测试/研究用途**；商用交付前请确认使用 **MIT BiRefNet** 或 **GPL-3.0 RVM** 权重（并在报告 `model.license_note` 核对）。
- **验收边界**：`matting-report.json` 记录 `adjacent_alpha_mad`、`min_fg_ratio`、`top_band_min_fg_ratio`、`max_frame_fg_drop` 与 `dropout_warning` 作为漏块/削顶/突变预警线索（无法替代人眼检查发丝边缘、快速运动残影与实际背景叠加效果），交付前须将 `matte.mov` 叠放至目标底图并用 `preview` 抽帧与完整播放核查。
