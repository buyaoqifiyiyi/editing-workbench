# Vlog、旅行与生活记录

适用于个人经历、生活过程、旅行体验主导的成片。旁白讲知识为主时改用 [讲解分区](explainer.md)；真实事件调查或人物访谈为主时改用 [纪实分区](documentary.md)。

## 片源与结构

区分人物口述、环境全景、活动过程、细节补画面和照片。先建立观众能理解的地点、人物和行动关系，再按经历、主题或情绪组织；不是每个文件都要用，也不默认按文件排序等同真实时间。

镜头长度依据体验与信息变化。关键动作留出发生和结果，风景可呼吸，重复走路或无新增信息的镜头可缩短。音乐片头或旅途小段可以采用 [节奏混剪](anime-mix.md)，随后回到正文的体验节奏；快切片头不能决定整条 Vlog 的速度。

片源含手持运动时，先区分自然运动和影响辨认的抖动，挑选可用范围。实际需要稳定、防抖、去噪或变速曲线时核对当前接口，不能在没有执行时宣称已修复。

## 转场与文字

用动作匹配、出入画、遮挡、景别或地点变化接剪。日夜、旅程章节或时间跳跃可使用轻转场；不为每次相邻镜头都加炫光和震动。横屏素材转为竖屏发布时可用 [`openedit auto-reframe`](../capabilities.md#auto-reframe) 做人脸跟拍重构图；开场短标题与画中画框可直接选用 [开源动效配方库](../recipes.md)（如 `title_card`、`lower_third`、`pip_card`），需要局部蒙版或成组位移时使用 `clips[].mask` 关键帧与 `composites[]`，但仍避免拖慢核心经历出现。实物从屏幕或道具里出现的合成，见 [绿幕选型](../green-screen.md#选型依据) 的两次实拍做法。

文字分地点/时间、人物口述字幕、短感想或章节标题，层级和位置保持一致。可读优先，装饰动画帮助体验而不抢过人物说话；不默认使用漫剪巨字或把所有信息做成短闪。时间、地点和行程路线按真实资料标注，缺少证据时用中性章节名，不编造打卡地点和拍摄日期。

## 动效层推荐组合

按 [动效层默认考虑](../../guides/planning.md#动效层默认考虑) 逐段设计，Vlog 与旅行片的动效以轻盈、跟随经历为主（参数见 [动效配方库](../recipes.md)）：

- **开场与章节**：地点/日期用 `title_card` 或 `kinetic_ui_title`（`reveal_style: "blur_scale_y"`）；每段旅程开头用 `lower_third` 标地点和时间。
- **记录感包装**：随手拍段落可叠 HyperFrames `viewfinder_hud` 取景框；照片串烧用 `polaroid_grid` / `filmstrip_reel`，优先传活视频 `video` + `source_in`。
- **切点与转场**：音乐重拍轻闪 `beat_flash`（`peak_opacity` 约 30–50）；日夜与地点跳转用 `wipe_transition` 或 `whip_transition`。
- **收尾**：结束语用 `title_card`，可配 `cinematic_bars` 收束画幅。

人物说话、表情与口型处不压字、不闪白，动效让位于经历本身。

## 声音与方法来源

保留有意义的环境声、人物口述、脚步或现场互动，音乐随段落调整，不能用持续满音量 BGM 淹没体验。用独立音频轨、源入点和淡化连接声音；现场音跨切点时检查人物话语是否被截断。源片仅有混合音轨时说明分离限制。

先从实际经历、现场声音和细节形成自己的叙事与观察角度；需要具体表现的实现依据时再查 [教学索引](../tutorial-library.md)。方法需要同机位、道具或真实路线时检查素材，不能为套教程新增虚构旅程。

计划与参数回读重点：经历/地点跳转的说明、必要动作起止、信息文字时段、人物与环境声保留及音乐增益。最终视听检查由用户完成。
