# 已学课程实战总手册（纯开源 OpenEdit 映射）

本手册把既往已研读的 15 大类系统课程与多位创作者实战方法（`全课程学习-20261007`、`秋叶剪辑` 41 集、`七七学剪辑` 第 214 集、`Need-it-L` 动漫排版、`帧帧爱剪辑` 10 集、`今天剪废了吗` 第 21 集与 81 套桌面模板结构）统一重构为 **OpenEdit 纯开源执行规范**，保留表达目的、前提条件与人工终审边界，全面移除原商业宿主菜单与旧软件限制。具体字段与工具边界查 [能力状态](capabilities.md)、[计划格式](plan-format.md) 与 [动效配方库](recipes.md)。

## 关键帧曲线、缓动与运动力学

- **先定起止状态，再选曲线**：先确定镜头起点、到位和停留状态与持续时间，不机械地给所有参数加关键帧。
- **瞬时速度看斜率 `dv/dt`**：值-时间曲线的变化快慢取决于斜率而非单纯幅度高低；同样变化量在更短时间内完成才更快。匀速推进、进度条与机械平移动画直接用 `linear`，不要一律套缓动。
- **独立轴与弯曲轨迹**：将横向匀速位移与非线性升降组合可得到抛物线或弧线轨迹（不等同于透视变形或素材变速）。
- **挤压与拉伸（弹跳案例）**：关闭等比后独立控制 `scale_x` 与 `scale_y`：接触前纵向略拉长、撞击帧扁压并随即纵向回弹，随高度衰减逐步收敛，末尾轻微收尾。物理落地还要满足回弹间隔随高度缩短，不能仅靠均匀时距凑数。
- **开源执行入口**：主剪辑写入 `clips[].keyframes[]`（支持 `position_x` / `position_y` / `uniform_scale` / `scale_x` / `scale_y` / `rotation` / `alpha`，`interpolation` 支持 `linear`、`smoothstep`、`easeIn`、`easeOut`、`bezier`、`hold`、`autoBezier`、`continuousBezier`），复杂非线性表达式或弹性图层交由 `overlays[]` 叠层编译为 `ProRes 4444 RGBA`。

## 抠像、边缘质检与前景穿插

- **按前景条件选型，不把单色键当万能**：
  - **均匀绿幕 / 蓝幕 / 单色底**：优先使用 `clips[].chroma`（默认 `ultra_key` 支持 `key_color`、`tolerance`、`choke`、`soften`、`spill`、`spill_luma`、`desaturate`；简单背景可用 `color_key`）。绿/白/蓝并非固定参数公式，须依实拍光线和背景阴影调节，避免同色衣物或高光反光被挖穿。
  - **非单色复杂背景人物或前景**：直接调用 [`openedit matting`](capabilities.md#ai-matting) 离线 AI 抠像（支持 `--gpu` CUDA 加速；自动发现本地 MIT `BiRefNet` 或时域 `RVM` 模型），直接输出带直通道 Alpha 的 `ProRes 4444 RGBA (.mov, yuva444p12le)` 与 `preview_rgba.png` / `preview_alpha.png`。商用交付优先选用 MIT `BiRefNet` 或 GPL-3.0 `RVM`，避免使用仅限非商业研究的 `RMBG-1.4`。
- **抠像前后的真实物理边界**：花枝、道具、手部遮住人物时，被挡区域没有像素证据，任何画笔或羽化都无法凭空还原被遮部位；羽化只用于融合过渡，过量缩边会吃掉发丝与指尖。
- **黑/灰/白三底验边与分层穿插**：输出透明度前景后，先后置黑底（查亮边/残片）、灰底（查轮廓锯齿）与白底（查内部漏空），再叠回真实目标背景查连续运动稳定性；前后穿插时复制两份同源同相位前景分置背景与夹层图形前后（详见 [绿幕与色度抠除](green-screen.md) 与 [主体与图形穿插](subject-graphic-interleave.md)）。

## 运动跟踪、失准修正与竖屏跟拍

- **单目标跟踪流程**：用 [`openedit tracking`](capabilities.md#offline-tracking)（OpenCV CSRT + PyAV 真实 PTS）框选纹理清晰、边界稳定且尽量少含背景杂波的参考区域，再用 `tracking-apply` 生成对应图层的 `position_x` / `position_y` 关键帧。
- **失准诊断与出画手工接续**：
  - 先排除“隐藏重复轨干扰”（可见前景层与参考层不一致导致轨迹乱跑），再缩紧采样框到清晰稳定区域；
  - 跟踪框架不包含自动遮挡重捕获：遇到高速模糊、目标出画或被另一物体完全遮挡时，按帧拆为“入画前 / 清晰可见段 / 再现后”分段跟踪，中间或出画残段以明确人工位置关键帧接续，隐私打码则需逐帧扫描边界并适当扩大安全半径。
- **横转竖智能跟拍**：需要 16:9 横屏转为 9:16 竖屏跟拍人物时，不再逐段手工打位置帧，直接使用 [`openedit auto-reframe`](capabilities.md#auto-reframe)（PySceneDetect / FFmpeg 硬切边界隔离，保证摇镜关键帧不跨切点滑动 + 本地 MIT OpenCV YuNet 人脸检测与梯度显著性回退 + 死区抑制与 `fit="cover"` 防黑边坐标）。

## 动态几何蒙版与钢笔贝塞尔遮罩

- **蒙版职责与类型**：FilmCraft 原生 [`clips[].mask`](plan-format.md) 支持 `rectangle`（`rect`）、`ellipse`（`circle`）、`polygon`、`bezier` 以及 `corner_radius`、`feather`、`opacity`、`expansion`、`inverted`、`mode`（`add`/`subtract`/`intersect` 等），支持按片段本地 `time` 对 `feather`、`opacity`、`expansion`、`path`、`center`、`size` 打关键帧；严禁拿几何矩形窗口假装人物轮廓抠像。
- **锐利硬边必须显式传 `feather: 0`**：FilmCraft 默认带约 `10px` 羽化，做条带拼合、分屏或干净斜切边界时务必指定 `feather: 0`，切点拼接建议临时用纯色底检验无漏缝或重叠再还原。
- **窗口运动与内容运动分离**：直接平移 `clips[]` 会连内容带遮罩一起移动；若要固定画面并让窗口扫过（靠关键帧间距控制慢过人脸、快过空区，窗口变速不等同素材 `speed`），应改动画 `mask.keyframes[]`，或先将内容与窗口分层装入 `composites[]` / 透明叠层内部预合成再进入主轨。
- **跨课程典型几何组合**：
  - 局部聚光与暗底压制：同源双层，上层用带羽化蒙版保重点，下层降不透明度或仅做 `mask` 局部范围调节；
  - 等分条带拼回整图：`N` 条竖分时带宽 `W/N`，第 `i` 条（从 `0` 计）像素中心 `x = (i + 0.5) * W / N - W / 2`，保持同源 `source_in` 与定量帧起点同步；
  - 影院弧形遮幅：上下置黑底并用压扁椭圆遮出弧边，须检查不压脸部与底栏字幕（详见 [组合方法](technique-combinations.md)）。

## 多级嵌套合成、字中视频与动漫分层排版

- **多级嵌套 `composites[]` 原则**：外层动画、整体裁切与调色放到嵌套组上，内层保留可编辑文字与独立素材时长（绝不用“定格图片”或烘焙视频替代可修改排版）；扩展外层持续时间前须先确认内层素材够长。
- **字中动态视频（原生可编辑路线）**：外层底为动态视频轨，上层为嵌套合成组（外层混合模式设为 `multiply` 或 `darken`），组内从底到顶放置“不透明黑底 + 纯白粗体文字（可选有色微偏移阴影）”，确保字外区域保持纯黑而非透明；需要人物穿插字间时，从底到顶按“原画底景 → 实体文字 → 透明人物前景 → 最顶层镂空描边或同内容描边层”同步对齐。
- **动漫人物分层排版五步法（借鉴 Need-it-L 实战思路）**：
  1. **边带与角标定版心**：用上下或四周背景色带、角落小字与次级装饰点线定出画面边界，文字标签先服从人物视线与构图重心，绝不抢脸部视觉中心；
  2. **人物透明分离与低透明重影**：先用 `openedit matting` 分离透明前景，再复制前景层略微位移并调低 `alpha` 夹在底景与清晰前景之间制造空间厚度（未分离人物而直接叠全图会导致背景双重混浊）；
  3. **双层偏移粗体立体主字**：主标题由浅色带细描边的前景字与深色微偏移后层共同建立面积和厚度（先定各自层级与锚点，主副字形成明显大小和字重差）；
  4. **平衡图形补空白**：人物一侧用大面积几何底圆或装饰框填补空白并可配合细斜体短句呼应主字；
  5. **分批错峰入场与尾帧齐剪**：标题、大圆、装饰与次字按先后顺序逐层到位（例如重影/边距先就位 → 标题分批入画 → 装饰圆形随后展开），避免全层同帧机械齐移；动效到位后留出可观读的稳定状态，末尾对齐全轨长度防止残影。换画幅比例（如 `2:1` 改 `16:9` 或 `9:16`）时须重算左右安全空间与字块面积。

## 超燃卡点接力与多图模板编排

- **超燃卡点五段接力链（借鉴七七第 214 集思路）**：
  1. **动作方向匹配**：先找挥击/跃起/转身方向一致或有落点接力的镜头配对，冲击效果只用来强化已对齐的动作接触；
  2. **四角错峰同尺度积累**：主背景持续播放时，上层以统一尺寸的小窗沿角落错拍出现，下方配套略大且带羽化的同期黑底框（可借助 `pip_card` 或同源蒙版副本）；
  3. **窄条“先快后慢”全幅接管**：积累至段落约 2/3 时切入一条窄条窗口（初始窄边），在约 1/3 处迅速拉宽完成大部分揭示，随后慢速平滑铺满全屏把多中心收回单一主体；
  4. **局部闪白与整屏爆闪分工**：小窗入画时的短时提亮仅盖当前新窗局部入画（`beat_flash` 置于对应窗轨或局部短剪辑），整屏爆闪（叠加在顶轨与切点对齐）专门负责大镜切换，不在原片自带高光刀光帧叠爆闪掩盖细节；
  5. **透明主体跨镜提前穿屏**：下一镜先切出前置短段并经 `openedit matting` 去背，让人物沿原本运动方向从画外滑入并叠在前镜背景上，穿过画面后无缝接进下一完整正片。
- **教程帧数按项目帧率换算**：教程常按 30fps 或 60fps 口述“3 帧 / 4 帧卡点”，迁移时须以音乐真实重音结合当前 `canvas.fps` 计算物理秒数（如 30fps 的 `3 帧 = 0.10s`，在 60fps 对应 `6 帧`）。
- **多图模板三类通用编排（81 套工程归纳）**：
  - **照片墙收束**：多张图片各就其位同时或错峰呈现后，收拢到主叙事或重点单张特写；
  - **多图轮播 / 滚动队列**：下层入画起点对齐上层完全到位之后的时间点，按共同步长和中心通过节点推进；重复滚动纹理时位移取周期整数倍且四边超出画布至少一个周期，防露底跳帧；
  - **严控异常时码与授权边界**：复现参考结构时按实记录片段时长与 `source_in`，绝不静默夹断越界关键帧掩盖报错；`openedit beats` / `beat-apply`（生成 `audio[].beat_marks`）+ [`overlays[].recipe`](recipes.md)（`beat_flash` / `pip_card` / `split_screen_frame` / `wipe_transition`）可快速落地大部分结构。

## 四角透视、3D 空间运镜与特效参数关键帧

- **四角倾斜与 3D 透视实现路径**：纯 2D 缩放与普通旋转不能冒充透视倾斜或 3D 空间摄像机；需要背景文字墙斜向透视面、屏幕四角贴合或真 3D 摄像机运镜时，使用声明式透明叠层 `overlays[]` 配合 AE 风格 JSX 脚本（`overlays[].script`）或 [`effectcraft-exec`](capabilities.md#effectcraft-overlays) 调用 3D 图层、相机/灯光及透视特效渲染为 `ProRes 4444 RGBA`。需要随镜头平面运动时，可结合 `openedit tracking` 追踪特征角点并保持可编辑性。
- **区分局部作用范围**：单片段 `clips[].effects`（或 `filters`）仅作用当前片段；`composites[].effects` 作用整个嵌套组下所有纳入轨道；高轨 `overlays[]` 叠加影响下方合成画面（注意部分发光/粒子特效若带实黑底需设置 `blend_mode: "Add"` 或 `"Screen"` 正确消黑）。
- **特效参数时序与渐变描边**：闪光、震动或变色冲击的通用节奏是 **`0 → 峰值 → 0`**（前段略陡快起、后段拉长慢退，避免持续整段高频闪烁），在 `overlays[].layers[].keyframes` 中精确写入参数起止关键帧；需要渐变色窗口描边时，可在主窗下方放置略大一圈且同源同步关键帧的纯色或渐变底框。

## 变速、倒放与当前能力边界

- **常速变速与倒放可用能力**：主时间轴完整支持 `clips[].speed`（`0.05..32.0`）与 `clips[].reverse: true`（需要独立生成倒放源段时亦可用 `openedit reverse`），以及音频独立 `audio[].speed`（`0.25..4.0`）。
- **改速必联动三处核对**：改变任一片段 `speed` 都会直接改变素材实际消耗时长，必须同步核验 `source_in + duration * speed <= source_duration`、下游切点衔接以及绑定对白/字幕的对齐状态；音乐主导作品须锁定 BGM 独立时间轴，不让配乐跟着画面一并变速变调。
- **明确未全自动内置的能力边界**：
  - **非线性曲线变速坡道（蒙太奇/英雄时刻等片内速度渐变）** 与 **智能光流补帧 / 帧融合慢动作**：目前均**未在纯开源主干中内置自动管线**；强行把低帧率素材拉慢不自动创造缺失动作帧，而光流算法在细线、刀刃、快速遮挡和粒子边缘极易出现拖影扭曲，遇到需要此类处理时须向用户如实说明边界或分段使用阶梯恒定 `speed` 衔接并查实际连续播放观感。

## 完整调色工作流：基础校正、曲线色轮与局部调色

- **先正色彩，再出风格**：先调白平衡（`temperature` / `tint`）与基础明暗（`exposure`、`contrast`、`highlights`、`shadows`、`whites`、`blacks`）保住皮肤、文字和暗部层次，再叠加风格曲线或 LUT（`input_lut`、`lut`、`look_intensity`、`vibrance`、`creative_sat`、`vignette`）。
- **亮度与偏色诊断**：看亮度分布分出暗部、中间调、高光各自空间，看 RGB 分量/矢量判断具体偏色区间后再微调对应区，不在未看画面时直接照抄青橙数值公式；动漫或高度风格化插画不硬套真人肤色基准线。过高的 HSL 饱和度与陡峭曲线会放大低码率片源的色块断层与暗部噪点。
- **跨镜头调节条 vs 局部调色（全部已映射 FilmCraft Lumetri）**：
  - **单镜头控制（`clips[].grading`）**：完整支持亮度/RGB 曲线（`luma_curve`、`rgb_curves`）、5 组 HSL/色相曲线（`hue_vs_sat`、`hue_vs_hue`、`hue_vs_luma`、`luma_vs_sat`、`sat_vs_sat`）、三区色轮（`wheels.shadows` / `midtones` / `highlights` 与各自亮度）、二级精细抠色 `hsl`（含单色简写 `red_hsl`/`green_hsl`/`blue_hsl`）以及内置椭圆遮罩局部调色 **`local_circle`**（`center` / `radius` / `feather` / `inverted` 等）；
  - **跨镜头“自定义调节层”等价做法**：将需要统一校色的相邻多段视频及多条轨道归入 **`composites[]`** 嵌套组并在组外层挂接 `composites[].grading`，即可像独立调节层一样跨多段统一校色且支持在 FilmCraft GUI 打开后随时微调。

## 声音处理、字幕高亮与口播粗剪一条龙

- **口播与混剪音频前置判断**：提取视频伴随音轨（仅分轨）不等于人声与伴奏分离；真实环境声支撑在场感的纪实或 Vlog 镜头切忌无脑全开降噪（易生水声/金属失真与吞掉尾音）。混音完成后必须正常速度试听人声与背景乐，削波警报和响度数字不代替实际听辨。
- **四步自动化纯开源音频/字幕工具链**：
  1. **人声与伴奏分离**：[`openedit separate --gpu`](capabilities.md#separation)（自动调用本机 MIT `htdemucs` ONNX 模型并可开启 RTX CUDA 加速，拆出 `vocals.wav` 与伴奏）。
  2. **去气口 + 转写 + 逐词高亮一键粗剪**：[`openedit rough-cut`](capabilities.md#rough-cut) 自动串联 `auto-cut`（Silero VAD v5 / FFmpeg 去静音气口）→ Whisper（`--gpu` CUDA 加速）词级转写 → 严格按片段边界限域的可编辑字幕工程（加 `--karaoke-mode` 自动生成逐词或逐短语卡拉 OK `highlights`；前期配合 `build --draft` / `export --draft` 半分辨率极速出预览）。注意明确区分三件事：遮挡条逐字出现 ≠ 静态重点词改色（`captions[].highlights`） ≠ 语音同步卡拉 OK 高亮；本地授权静态字体可直接传入 `captions[].font_path` 而无需污染软件安装目录，专有名词与数字转写后仍须人工核对。
  3. **音乐四点自动闪避**：[`openedit ducking`](capabilities.md#ducking) 依据人声包络或语音时间戳生成严格 `t=0` 起步递增的四点平滑退让音量关键帧 `audio[].keyframes`（前降→低位平台→回升平滑，避免硬切音乐断层）；FFT 频谱降噪使用 `openedit denoise-audio`。
  4. **统一响度母带与削波体检**：[`openedit audio-master`](capabilities.md#audio-master) 通过 FFmpeg 双遍线性 EBU R128 `loudnorm` 输出 `streaming`（`-14 LUFS`）、`podcast`（`-16 LUFS`）或 `broadcast`（`-23 LUFS`）预设成品及 `loudness-report.json`（含 `--measure-only` 只测模式，多轨粗剪亦可同步挂 `audio[].loudness`）。
- **声音能力明确边界**：目前**尚未单设独立的多段参量均衡器 EQ（频点 / 增益 / Q 值）CLI 操作**；涉及复杂多频段人声修整或空间声场时，可保留无损混音轨道交由外部开源音频工具处理或如实标注给用户做最终审校。
